# AI 품번 결과 가져오기 (새 기능 브랜치)

기준 최적화 완료 0b30c3ac2316308879fa755ff6979a7b63b8e993. 기존 검증 브랜치 및 PR #3 그대로 유지. 사용자 요청으로 게임 정보 수집창의 AI 가져오기 기능만 추가.

1. 기존 공식 수집 완료 후 품번 없는 항목 TXT/복사. AI는 PlayDock_Identity_Import version 1 JSON만 반환. DLsite 우선 Steam 후순위, 확인/검토/미확인 구분, 합본/패치/MOD 오판 금지, 원본 이름 유지.
2. AI 결과 가져오기 → JSON/TXT 파일 또는 붙여넣기 → 정확히 같은 현재 원본 파일명만 매칭 → 후보와 제외 이유 미리보기 → 사용자 승인.
3. 기존 품번(수동 삭제 포함), DB 연결, 중복, 잘못된 URL/품번, 미확인 및 현재 목록 외 대상은 보존/제외. AI URL 직접 접속 금지. 코드 전용 기존 공식 엔진으로 다시 확인하며 등록 후보만 백그라운드 수집. 동일 store/code 확인 후 기존 meta.json과 DB 연결에 기록. DB 스키마 및 원본 파일 변경 없음. 공식 사이트에서 코드가 실재함과 실제 압축파일 정체가 일치함은 별개이므로 사용자 미리보기 확인 필요.
4. 이후 정보 수집에서 명시적으로 등록한 품번도 포함. 표시명은 기존 표시 품번 규칙에 따라 품번이 붙을 수 있지만 수동 제목 원문·압축파일명·게임 ID·모음집·이미지·실행 옵션 유지.
5. 변경 승인 범위: controllers/catalog_collection.py, ui/dialogs/catalog_collection.py 및 새 가져오기 창만. 기존 UI 기준 문서/원본 SHA 그대로 유지, 나머지 UI 보호 소스 변경 금지.
6. 검증: 가져오기 정합/거절/실패/Steam·DLsite/재수집/중복/기존 코드 보존 및 UI 신호 테스트, 전체 Windows 회귀 및 정식 빌드. 실제 공식 사이트 검증과 사용자 PC는 별도. main 병합 없음.

## 조사 프롬프트 개선
실제 웹 검색, 검색용 제목 정리, 다국어/원제/제작사 교차 검색, DLsite 우선·Steam 후순위 공식 상세 페이지 직접 확인을 요구한다. 단순 버전/언어 차이를 별개 작품으로 자동 간주하지 않으며 합본·패치·MOD 단독은 보수적으로 판정한다. 모든 결과에 reason(근거 또는 실제 실패 이유)을 추가하되 기존 version 1 가져오기 파서는 추가 필드를 무시하므로 UI 표시/저장 기능은 이번 범위에 포함하지 않는다. UTF-8 JSON 파일 반환 및 다시 파싱 검사, HTML 엔티티/역슬래시 등 깨진 출력 방지를 명시한다. 검색 성공률 향상은 실제 AI 재조사 전에는 확정할 수 없다. 프로그램의 가져오기 로직·UI·DB·원본 게임 파일은 변경하지 않는다.
