# 공식 배너·아이콘 적용 범위 분리

사용자 요청: 상단 기능은 전체 라이브러리, 게임 관리 메뉴는 현재 선택 게임. 상단은 현재 선택·검색·정렬·모음집 화면에 관계없이 전체 게임의 검증된 DB 연결과 이미지 후보를 검사한다(일괄 DB 읽기, 수동 품번 삭제 유지). 공식 이름 일괄 메뉴는 유지. 하단 게임 관리에 기존 단일 공식 이미지 적용을 추가하고 수동 설정 및 실행 옵션 등 유지.

일괄 적용 창: 게임별 배너/아이콘 체크, 기본 미선택, 빈 이미지 전체 선택, 선택 해제, 기존 이미지 교체 시 별도 승인. 후보 URL은 공식 DB의 신뢰 가능한 URL만 사용, 선택한 이미지만 기존 적용 서비스로 저장(백업 유지). 한 게임씩 백그라운드 처리, 중단 가능, 누락/실패 표시, 마지막 한 번 새로고침. 메인 UI 배치·색상·DB 스키마·압축파일은 변경하지 않는다. 기존 UI 보존 기준은 과거 기록 그대로 보관하며 이번 메뉴 변경은 사용자 승인 범위이다. 실제 Windows 및 다운로드 성공률은 CI/실사용 확인 필요. main 및 기존 최적화 브랜치 변경 없음.

전체 선택 버튼을 추가하여 전체 후보를 한 번에 선택할 수 있다. 기존 이미지 포함 시 별도 교체 확인은 유지하며, 대량 선택 때는 체크박스 변경 신호를 일시 차단하여 전체 목록을 반복 계산하지 않는다.
