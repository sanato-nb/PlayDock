# 9단계 Windows 실행 검증

9-J 사용자 개인 PC 검수는 요청에 따라 제외한다. 실제 사용자 데이터 및 게임 실행 파일은 사용하지 않는다.

- 9-A/B/C: 실제 PySide6 창 생성, 화면 캡처, 버튼·메뉴·모달 대화상자, Qt 이벤트 루프 종료. 호스팅 Windows 네이티브 Qt 플랫폼도 별도 실행하며, 사용자 모니터 검수와 구분한다.
- 9-D: Qt 오프스크린 100/125/150/200% 배율과 950×620, 1280×720, 1920×1080 요청 창 크기. 실제 캡처 크기와 DPR을 기록한다.
- 9-E/F/G: 합성 ZIP 100/500/1000/5000개 및 10% 설치 폴더. 같은 Windows runner에서 직전 기준 86635400e4c925ddfd63e144112eaaf27f50b와 현재 소스를 비교. 준비 시간 제외, 열기/갱신/검색/정렬/상세/모음집/이름 미리보기/로컬 이미지, CPU 시간과 RSS 표본, 상세 조회 호출 수 및 결과 해시를 기록한다. 시작 시간 1회 및 작업별 2~3회 표본으로 장기 평균을 주장하지 않는다.
- 9-H: 합성 100개 목록의 60초 반복 조작. 메모리 표본과 성공 반복 수를 기록한다.
- 9-I: 공개 공식 사이트의 Steam 및 DLsite 예시 ID 각 1개, 실제 접속 결과를 성공/미확인으로 구분. 미확인은 미등록으로 해석하지 않는다.

EXE 빌드와 main 병합은 실행하지 않는다. 결과는 GitHub Actions 증거로 저장한다.
