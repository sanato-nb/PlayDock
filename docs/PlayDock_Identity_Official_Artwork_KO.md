# PlayDock 게임 정체 판독 · 공식 배너/아이콘 체크박스

## 사용자 동작
1. PlayDock에서 압축파일 게임을 하나 선택한다.
2. 게임 정보 아래 **게임 정체 판독** 버튼 또는 게임 관리/우클릭 메뉴의
   **게임 정체 판독 · 공식 이미지 적용...**을 누른다.
3. 별도 UI 스레드가 아니라 기존 독립 판독기에서 검증한 **품번 전용
   DLsite → Steam 엔진**을 실행한다. 압축파일을 해제하지 않고 이름을 변경하지 않는다.
4. 공식 품번과 이름이 **하나만 명확하게 검증되면**, 그 작품의
   공식 페이지와 공식 이미지 메타데이터를 이용해 배너/아이콘 후보를 수집한다.
   - DLsite: 공개 사이트에서 확인되는 표지와 샘플 이미지 URL
   - Steam: 동일 App ID의 공식 공개 Store JSON에 기재된 헤더·캡슐 이미지 URL
   - 이미지 생성, 유료 AI API, 임의 이미지 검색 사이트 이용 없음
5. 두 이미지를 미리보고 **배너 적용**, **아이콘 적용**을 각각 체크한다.
   **기본값은 둘 다 해제**. 공식 이미지가 없거나 다운로드에 실패한 항목은
   선택할 수 없으며, 기존 이미지를 유지한다.
6. **작품정보 저장 · 선택한 이미지 적용**을 누르면 공식 작품정보가 통합
   `works` 테이블에 저장된다. 이미지 원본 URL은 `works.images_json`에 저장.
   사용자가 체크한 항목만 기존 게임별 `cache/{game_id}/hero.png` 또는 `icon.png`
   파일을 교체한다. 체크하지 않은 이미지 파일은 바이트 하나도 수정하지 않는다.
7. 선택한 이미지가 이미 존재한다면 덮어쓰기 여부를 **별도 확인**하고,
   실제 교체 전 `data/backups/artwork/{game_id}`에 원본을 백업한다.
   교체를 거절하면 이미지 변경 없이 공식정보만 DB에 저장한다.

## 저장과 검증 규칙
- DB는 기존 합의대로 `PlayDock/data/playdock.db` 파일 하나,
  `works`·`library_links` 테이블 둘을 사용한다.
- `store + code`로 작품을 식별하며 확인되지 않은 작품의 이미지는 적용하지 않는다.
- 이미지 URL은 DLsite 공식 도메인 또는 **같은 Steam App ID가 포함된**
  공식 Steam CDN 도메인만 허용한다.
- HTTP 결과 크기, 이미지 포맷, 이미지 픽셀 수, 외부 HTTPS 및 DNS/리디렉션
  안전 검사는 기존 PlayDock 이미지 코드의 검증을 사용한다.
- 사용자 지정 제목·압축파일·모음집·설치 파일은 변경하지 않는다.
- 다른 사이트의 공개 이미지는 해당 사이트의 이용 조건/권리에 따라 재사용이
  제한될 수 있다. 사용자 개인 라이브러리 표시 용도로만 적용한다.
- Steam 이미지 메타데이터가 없거나 사이트 접속이 차단된 경우, 공식 작품정보
  조회 성공은 유지하되 해당 이미지 체크박스를 비활성화한다.

## 역할
- 독립 정체 판독기: 정확도·속도 개발 및 별도 검증용 도구.
- PlayDock 본체: 같은 정체 판독 엔진을 통합 호출해 작품정보와 체크된 아트워크를 적용.
- 사용자는 최종적으로 **PlayDock.exe 하나**에서 판독을 실행한다.
