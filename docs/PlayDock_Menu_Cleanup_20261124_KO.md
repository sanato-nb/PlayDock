# PlayDock 메뉴 통합 — 2026-11-24

## 메뉴 배치

| 위치 | 기능 | 조건 |
|---|---|---|
| 우측 상단 | 게임 정보 수집 | 항상 가능, 품번 없는 게임은 조회 대상 제외 |
| 우측 상단 | 새로고침 | 라이브러리 재스캔 |
| 우측 상단 **기능** | 공식 배너·아이콘 적용 | 선택한 게임에 공식 DB 연결과 신뢰된 이미지 URL이 있어야 가능 |
| 우측 상단 **기능** | 공식 게임명 설정 (여러 게임) | 수집 완료된 공식 작품 연결이 하나 이상 필요 |
| 우측 상단 **설정** | 폴더 설정, 데이터 관리, 라이브러리 속성, DB 상태 확인 | 운영/관리 전용 |
| 선택 게임의 상세 화면 **게임 관리** | 게임 이름 변경 (수동), 배너·아이콘 수동 설정, 실행 옵션 설정, 공식 작품 페이지 열기 | 해당 게임 1개만 적용 |

## 정리 사항

- AI 설정은 메인 설정 메뉴에서 제거했습니다. 기존 저장된 사용자의 설정값이나 자격증명은 삭제하지 않습니다.
- 일괄 이름 설정과 이미지 보관 폴더 열기를 일반 설정 메뉴에서 제거하고 공식명 일괄 적용은 상단 기능 메뉴로 이동했습니다.
- 게임 목록 우클릭 메뉴에서는 중복 편집 및 세이브 백업/복원을 제거하고 모음집·설치·제거·연결 해제 기능만 유지합니다.
- 수동 이름 변경은 선택 게임 하나의 화면 표시 이름만 수정합니다. 원본 ZIP·7z·RAR를 바꾸지 않습니다.
- 공식 이미지 적용은 작품정보 연결만으로 활성화되지 않습니다. `works.images_json` 안에 신뢰할 수 있는 `hero` 또는 `icon` URL이 필요합니다.
- 이미지 적용 QThread는 선택한 게임에 이미 연결된 `(store, code)`의 레코드를 직접 조회하여, 압축파일명에 품번이 없어도 불필요한 재판독이나 ValueError를 피합니다.
- 이미지 설정 창에서는 배너와 아이콘 기본 체크를 해제하며, 사용자가 선택하지 않은 이미지는 바꾸지 않습니다.
- 공식 게임명 설정은 기존 일괄 미리보기·확인 창을 재사용하며 처음부터 '공식 게임명 적용 (수집한 DB)' 모드를 선택합니다.
- `main`은 변경하지 않고 `feature/game-management-menu-20261124` 브랜치에서 검증합니다.
