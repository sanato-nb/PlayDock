# PlayDock v0.8.0 — 작품 정보 DB 안내

## 목적

PlayDock는 ZIP / 7z / RAR 압축파일로 보관된 게임을 관리합니다. `data/playdock.db`(SQLite)에 **작품 정보**와 **로컬 게임 연결**을 저장하여, 매번 같은 작품을 검색하지 않아도 되도록 했습니다.

## 첫 시작 시 생성

- 기존 프로그램 설치 폴더의 `data/` 아래에 `playdock.db`가 자동 생성됩니다.
- 기존 `settings.json`, `collections.json`, `cache/<게임ID>/meta.json`, 이미지 캐시는 그대로 사용합니다.
- 기존 게임의 실제 ZIP/7z/RAR, 압축을 푼 게임, 바로가기 등은 변경하지 않습니다.
- 사용자 기록이 들어 있는 DB는 공개 배포 ZIP에 포함하지 않습니다. 새 사용자 DB는 빈 상태에서 시작합니다.

## DB에 저장하는 항목

| 테이블 | 주요 항목 |
|---|---|
| `works` | 작품 코드(RJ/VJ/BJ/EJ), 기본 제목, 제작사/서클, 발매일, 원본 작품 페이지 URL, 조회 출처·시각 |
| `work_titles` | 작품 코드 + 실제 언어별 제목 (`ko`, `ja`, `en`); 원제만 있으면 한국어를 거짓으로 표시하지 않음 |
| `work_tags` | 장르/태그 |
| `work_images` | 표지/썸네일/샘플 **이미지 URL** (이미지 바이트 자동 다운로드 없음) |
| `library_links` | 현재 사용자 게임 ID, 원본 파일명, 압축파일명, 연결된 품번, 마지막 확인 시각 |

게임 목록은 압축파일 폴더를 재검색해 연결합니다. DB가 게임 설치/실행 파일을 복사하거나 수정하지 않습니다.

## 앱에서 사용하는 방법

1. 게임을 선택합니다. 파일명에 `RJ390522`처럼 품번이 있거나 게임 이름 관리자에서 품번을 지정할 수 있어야 합니다.
2. **게임 관리 → DLsite 작품 정보 조회 · DB 저장...** 또는 **게임 목록 우클릭 → DLsite 작품 정보 조회·DB 저장...**를 누릅니다.
3. DB에 기록된 품번이면 **저장된 정보 보기** 또는 **DLsite 새로 조회**를 선택할 수 있습니다.
4. 제작사·발매일·장르·언어별 제목·이미지 URL 개수를 확인합니다.
5. **DB에 저장**을 누르면 `playdock.db`에 기록됩니다. 표시 이름까지 변경하고 싶을 때만 체크박스를 켭니다.
6. 저장된 작품의 게임 상세 화면에 DB 작품명·제작사·발매일·장르가 표시됩니다.

**품번이 없는 게임:** DLsite 품번 조회는 불가능합니다. 기존 게임 이름 관리자/무료 웹 이미지 검색으로 검색하거나, 품번을 확인해 등록해야 합니다. 추측한 품번을 자동 적용하지 않습니다.

## DLsite의 데이터 제공 형태와 주의사항

- 확인된 경로 예시: `https://www.dlsite.com/maniax/api/=/product.json?workno=RJ390522&locale=ja_JP`
- 위 경로는 **사이트 내부 JSON 엔드포인트를 비공식적으로 이용**하는 방식입니다. 일반 개발자가 사용할 수 있도록 보장된 공식 공개 API 문서나, DLsite가 공식 제공하는 전체 작품 DB는 확인하지 못했습니다.
- 접근 제한, 작품 삭제/비공개, 성인 인증 제한, JSON 형식 변경이 있을 수 있어요.
- 한 게임을 선택해 조회한 경우에만 네트워크 요청합니다. 대량 수집, 우회, 자동 전체 DB 다운로드 기능은 넣지 않았습니다.
- DLsite의 타이틀·표지·샘플 이미지에 대한 권리와 재배포 조건은 별도로 확인해야 합니다. **DB에는 이미지 URL만 저장하고 이미지는 자동으로 공개 배포하지 않습니다.**
- 원본 작품 정보 확인 버튼을 통해 직접 DLsite 페이지를 열 수 있습니다.

## 백업 · 복원

`데이터 관리 → 백업`에 `playdock.db`가 포함됩니다. 복원하기 전에는 기존 데이터가 자동 백업됩니다. 실제 게임 압축파일·게임 설치 폴더는 백업하지 않습니다.

## API 키/개인 정보

- 작품 정보 조회에 OpenAI/Gemini 등의 유료 AI API 키는 필요하지 않습니다.
- DLsite 구매 내역이나 DLsite 계정 자격 증명을 사용하지 않습니다.
- 유저의 압축파일 경로나 게임 설치 경로를 DLsite에 전송하지 않습니다. **작품 코드만 요청 URL에 담습니다.**
- 배포 ZIP의 `data/`는 빈 폴더입니다. 개인 게임 목록·모음집·캐시·기존 DB를 포함하지 않습니다.

## 검증 한계

SQLite 저장/읽기, 작품코드 일치 확인, 모의 DLsite JSON, 데이터 백업/복원, 공개 배포 개인정보 제외는 자동 테스트했습니다. **실제 DLsite 네트워크 호출, Windows GUI, Windows EXE 빌드/설치는 현재 작업 환경에서 검증하지 못했습니다.**

기존 v0.7.7 PDF 사용설명서는 기초 기능 설명서로 함께 제공하며, 새로운 DB 기능은 이 문서를 참고하세요.
