## 증거와 검증
source_manifest.json: UI 관련 소스 및 컨트롤러 38개 파일의 Git blob SHA와 크기. 변경이 필요한 코드라도 외관 및 동작을 유지해야 하며 변경 목록을 비교해 검토한다. 기준은 사용자 승인 없이 교체하지 않는다.
capture_ui_reference.py는 합성 자료로 동일 Qt/Windows runner에서 기준과 현재 화면을 각각 캡처한다. 메뉴 구성/활성화, 주요 치수, 스타일 SHA, 버튼 구조를 비교한다. 실제 이미지 및 결과 JSON은 GitHub Actions artifact에 저장하며 기존 UI 회귀 테스트도 실행한다. 픽셀 완전 일치, Windows 네이티브 타이틀바·Tk 설치기·고 DPI 렌더링은 offscreen 캡처만으로 보장하지 않는다. 실제 Windows EXE 확인은 최종 검증 단계에서 별도 필요.
UI 기준 추가는 소스 동작 수정이 아니다. 향후 변경 시 이 기준으로 비교하며 의도치 않은 화면 변경은 기능 최적화 완료로 판정하지 않는다.

원본 기준 SHA는 유지한다. 2026-11-24 기준 artifact 14903529939의 PNG 14쌍 RGB 픽셀을 독립 비교하여 모두 일치함을 확인했다. 다만 일부 글리프가 사각형으로 렌더링된 캡처를 확인했으므로 실사용자 화면 품질 승인으로 해석하지 않는다. 최신 검증에서는 동일 fixture 경로, 버튼·라벨·입력창·프레임 좌표 및 크기, 메뉴 계약, 실제 PNG 픽셀 SHA/차이 영역/차이 픽셀 수, Qt와 기본 글꼴 정보를 기록한다. 정적 화면 차이와 보호 소스 변경은 실패 조건이며, 동적 경로/DB/파일 선택창 차이는 별도 수동 검토 대상으로 표시한다. 네이티브 타이틀바 및 실제 한글 표시, DPI, Tk 설치·제거기 검수는 실제 Windows 확인 필요.
