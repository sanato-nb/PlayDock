# PlayDock 사용 안내 (v0.7.7)

PlayDock는 내가 가진 ZIP·7z·RAR 게임 압축파일과 이미 설치된 Windows 게임을 한 곳에서 설치·실행·정리하는 로컬 게임 라이브러리입니다. 실제 게임 파일을 자동 제공하거나 게임 인증을 우회하지 않습니다.

## 처음 설치하기

1. `PlayDock_Setup.exe`를 실행합니다.
2. **프로그램 설치 폴더**를 선택합니다. 예: `D:\PlayDock` (실행 파일과 `data`가 함께 들어갑니다).
3. **게임 압축파일 폴더**를 선택합니다. 예: `D:\Games\Archives`.
4. **게임 설치 폴더**를 선택합니다. 예: `D:\Games\Installed`.
5. 바탕화면 바로가기 여부를 결정하고 설치를 완료합니다.

## 게임 설치·실행하기

- 왼쪽에서 게임을 고른 뒤 **설치**를 누르면 압축을 해제해 설치합니다. 원본 압축파일은 유지합니다.
- 설치된 게임은 **플레이**를 누르면 실행할 수 있습니다. EXE가 확실하지 않으면 **EXE 선택**에서 지정합니다.
- 처음 실행하는 EXE만 확인창이 표시될 수 있습니다.
- 게임을 우클릭해 **설치 제거 (휴지통으로 이동)**를 선택하면 압축 해제된 게임 폴더를 휴지통으로 이동합니다. 게임 폴더 안의 세이브도 함께 이동할 수 있으니 주의하세요.

## 기존 게임 / 모음집

- 이미 설치한 외부 게임: 왼쪽 **+ 게임 등록** → 해당 `.exe` 선택. 실제 파일 이동 없음.
- 분류: **+ 새 모음집** → 게임 선택 → **모음집에 추가 / 제거**.
- 모음집 카드 보기: 상단 **내 모음집**. 이름 변경·삭제는 모음집 우클릭.

## 게임 배너·아이콘 변경

1. 게임을 선택하고 **인터넷 이미지 검색·편집**을 누릅니다.
2. 작품명/품번이 맞는지 확인한 뒤 **이미지 검색**을 누릅니다.
3. 후보의 **출처**를 확인한 뒤 **선택 · 편집**을 누릅니다.
4. 드래그 또는 슬라이더로 자르기 위치와 확대를 맞춘 뒤 **이미지 적용**을 누릅니다.
5. 배너는 1600×520, 아이콘은 256×256으로 저장됩니다.

이 과정에는 이미지 생성 API가 필요하지 않지만 인터넷 이미지의 정확성·저작권은 직접 확인해야 합니다.

## 게임 이름 변경·복원

게임을 선택하고 **게임 관리 → 게임 이름 수정 / 이름 관리자 열기**를 누릅니다. 간편 수정에서는 직접 새 이름을 저장할 수 있고, **이전 이름으로 되돌리기** 또는 **원본 파일명으로 복원**이 가능합니다. **상세 기능 보기**에서 RJ 품번 조회, 한국어 제목 웹 검색, 언어별 제목, 일괄 이름 수정 기능을 이용합니다. 실제 압축파일 이름은 변경하지 않습니다.

## 백업과 데이터

- **데이터 관리 → 백업 · 복원 → 전체 데이터 ZIP 백업**: 설정, 모음집, 이름, 이미지 캐시 등을 백업합니다.
- **게임 파일과 세이브 파일, Windows에 저장된 API 키는 전체 데이터 ZIP에 포함되지 않습니다.**
- 게임 세이브는 **게임 관리 → 세이브 폴더 백업**에서 해당 폴더를 직접 지정해 따로 백업합니다. 복원은 새 폴더로 압축 해제되며 기존 세이브를 덮어쓰지 않습니다.
- 프로그램 제거는 Windows의 **설치된 앱** 또는 `PlayDock_Uninstall.exe`로 진행합니다. 게임 우클릭의 **설치 제거**와는 다른 기능입니다.

## 문제가 생기면

- 게임이 안 보임: **폴더 설정** 경로 확인 → **새로고침**.
- 설치 오류: 압축 비밀번호·손상·남은 공간·RAR 해제 도구 확인.
- 실행 안 됨: **EXE 선택**으로 실행 파일 지정.
- 이미지가 잘못됨: 제목이나 RJ 품번을 확인하고 출처를 비교.
- 이름이 적용 안 됨: 이름 관리자에서 저장 후 본체 **새로고침**.
- AI 오류 429: API 한도 확인. 404: 모델 이름과 지원 여부 확인.
