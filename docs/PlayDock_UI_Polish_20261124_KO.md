# PlayDock 검수 후 UI 개선

- 기존 기능·게임 관리·설정 메뉴 구성 및 콜백을 유지하고 항목 이름 끝 말줄임표만 삭제.
- 기능 버튼은 선택 게임의 검증된 공식 이미지 또는 라이브러리의 확인된 공식 작품 연결이 있을 때만 활성화. 기존 DB 사용, 수집 완료/새로고침/선택/화면 변경에 따라 갱신.
- 라이브러리와 내 모음집 버튼을 실제 QStackedWidget 화면과 연동. 현재 화면의 버튼만 파란색.
- Qt 파일·폴더 선택 창에 공통 스타일, 밝은 탐색 아이콘, 한국어 레이블/툴팁, 행 강조 및 기본 창 크기, QSizeGrip 제거, Windows 제목 표시줄 재적용. 기본 창 테두리 및 파일 선택 기능 유지.
- 테스트는 임시 라이브러리/가짜 압축파일만 사용. Windows 실제 화면에서 제목 표시줄과 크기 조절 손잡이 렌더링은 추가 확인 필요.

## 파일 선택 창 제목 표시줄 후속 수정

실사용 검수에서 Windows 네이티브 제목 표시줄이 흰색으로 남는 현상을 확인했습니다. 파일·폴더 선택 창만 PlayDock 자체 다크 제목 표시줄을 사용하도록 변경하여 Windows 테마 및 DWM 적용 시점에 의존하지 않습니다. 기존 Qt 파일 탐색, 필터, 선택 및 저장, 취소, 창 이동/테두리 크기 조절을 유지합니다. 실제 화면의 색상은 사용자 Windows 검수에서 확인합니다.
