# PlayDock · 정보 수집 → 이미지 설정 → 이름 설정 (2026-11)

## 메인 화면
**게임 정보 수집**은 품번으로 DLsite→Steam 공식 작품을 조회하고, `works`의 작품정보 및 `library_links`의 **게임별 확인 연결**을 저장합니다. 수집이 끝난 게임의 배너·아이콘 설정만 활성화됩니다.
**배너·아이콘 설정**은 더 이상 게임 정체를 조회하지 않습니다. DB에서 공식 확인된 작품을 읽고, 공식 이미지 URL을 다운로드해 체크박스 미리보기를 표시합니다.
**게임 이름 설정**은 선택한 게임을 기본 대상으로 하며 다음 모드를 제공합니다: `공식 게임명 적용 (수집한 DB)`, `직접 이름 수정`, `최초 압축파일 이름으로 표시 이름 복원`, `이전 이름으로 되돌리기`.

## 데이터 보존
- 공식 작품은 DB의 `(store, code)` 기준으로 한 번만 저장합니다.
- `library_links(game_id, store, code)`는 정보 수집에서 공식 품번을 단일 확인한 게임과 연결합니다. 다시 새로고침해도 수집한 연결을 지우지 않습니다.
- 확인 실패, 품번 없음 또는 여러 작품이 모호하게 확인된 게임은 자동 연결하지 않습니다.
- 최초 정보 수집을 시작할 때 각 게임의 `meta.json`에 `original_archive_name`을 **한 번만** 기록하여, 이후 표시 이름을 복원할 수 있게 합니다.
- **실제 ZIP·7z·RAR 파일명은 수정하지 않습니다.** 게임 ID 및 모음집을 유지하기 위해 실제 파일명 변경/복구는 이번 업데이트 범위에 포함하지 않았습니다.
- **수집은 이미지 파일을 절대 변경하지 않습니다.** 배너/아이콘 설정 창에서 실제 공식 이미지가 있는 항목만 개별 체크해 적용합니다.
- 체크하지 않은 이미지는 보존하고, 이미 있던 이미지를 체크하면 교체 전 확인과 원본 백업을 실시합니다.
- 공식 게임명 적용은 **사전에 수집된 DB에 링크가 있는 게임만** 후보가 됩니다. 정보가 없으면 일단 직접 수정/표시 이름 복원 기능만 사용 가능합니다.
- 기존 `PlayDock.exe` 내 개별 편집기와 모든 사용자 메타데이터, 설치 폴더, 이미지 캐시, 모음집은 보존합니다.

## 순서
1. 상단 또는 게임 관리의 **게임 정보 수집**을 실행합니다.
2. 성공한 게임의 정보 영역에 `공식 작품 확인: DLSITE · RJ...` 혹은 `STEAM · 1091500`이 표시됩니다.
3. 게임 선택 후 **배너·아이콘 설정**에서 원하는 이미지 종류만 체크하여 적용합니다.
4. **게임 이름 설정**에서 공식 제목을 확인하고 변경 전후 미리보기에서 선택된 게임만 저장합니다.

## 개발 검증
`tests/test_collected_game_workflow_v3.py`로 DB 연결 유지, 정보 수집 전 잠금, 이미지 모드에서 검색 재호출 금지, 공식 게임명 DB 우선, 원본 압축파일명 복원 및 파일 무변경을 검증합니다.

## 2026-11 사전 필터 및 AI 조사 인계 UI
- **게임 정보 수집 버튼은 메인 화면이 아닌 우측 상단**, 새로고침/설정 앞에 있습니다.
- 시작하기 전 압축파일명에서 DLsite 작품 번호(예: RJ01081508) 또는 명시된 Steam App ID를 추출합니다.
- **압축파일명에 품번 또는 Steam App ID가 없는 경우 공식 사이트 조회 대상에서 사전 제외**합니다.
- 진행 창에 수집 대상·제외 숫자를 분리해서 표시하고, 제외 게임 파일명은 목록에 기록합니다.
- 공식 조회 종료 후에만 **품번 없는 게임 AI 조사 프롬프트 복사** 및 **TXT 저장** 버튼을 활성화합니다.
- 프롬프트에는 파일명(상대적인 basename)만 들어갑니다. 절대 경로·사용자 데이터베이스·자격 증명은 넣지 않습니다.
- AI가 반환한 품번은 **수동 검증 대상으로만 활용**합니다. 실제 압축파일 이름 자동 변경/DB 자동 덮어쓰기는 하지 않습니다.
- 취소/조회 오류가 있을 때 프롬프트 버튼을 활성화하지 않습니다.
- **배너·아이콘 설정 활성화 버그 수정:** 게임 선택, 새로고침 및 정보 수집 종료 시 선택한 게임의 작품 연결정보를 조회해 즉시 버튼을 갱신합니다.
- 수집 전 다른 기존 표시 이름·수동 이미지 설정·압축파일·모음집은 변경하지 않습니다.
