# 5-B 대량 게임 검색·정렬 및 모음집 인덱스 최적화

기준 e4c86cfc1e603d5abaf22f377214c970626e60cb. 5-A 집중 검증 성공, 전체 및 빌드 검증 진행 상태에서 시작. https://github.com/sanato-nb/PlayDock/actions/runs/45358161420

사이드바는 정렬된 게임 목록을 모음집마다 다시 순회하여 게임 ID를 계산하고 마지막에 미분류도 별도 계산했다. 모음집 개수 C, 필터 후 게임 N에 대해 ID 조회 (C+1)*N 회. 임시 역방향 membership 인덱스를 만들어 ID 조회 N 회로 줄인다. 전체 모음집 화면의 멤버 구성도 같은 공통 함수를 이용한다. 인덱스는 각 갱신에서 생성하며 영구 저장하지 않는다. 검색 문자열 정규화도 게임당 한 번으로 줄인다.

기존 정렬 순서, 동일 게임의 여러 모음집 소속, 빈 모음집, 누락 ID, 중복 ID 처리 및 미분류 유지. 저장된 모음집과 DB/메타/이미지 변경 없음. 개별 모음집 진입과 기존 title 계산 방식 유지. ID 조회 횟수 측정은 해당 그룹 구성 작업만 대상으로 하며 전체 GUI 로딩 시간 또는 디스크 I/O 수치가 아니다.

합성 5000게임, 50모음집에서 사이드바 그룹 ID 호출 255000→5000, 전체 모음집 멤버 구성 250000→5000 기대값 검증. 추가 테스트 29개, 전체 Windows 회귀. 실측 결과는 CI에서 기록한다.
