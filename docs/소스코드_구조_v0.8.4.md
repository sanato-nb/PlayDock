## 호출 흐름

`UI`는 버튼과 화면만 만들고, `Controller`가 적절한 `Service`에 작업을 요청합니다. `Service`는 `Model`과 파일을 이용해 실제 게임 작업을 처리합니다. `database/`는 SQLite 저장에 집중하고, `integrations/`는 외부 정보 요청에 집중합니다.

기존 `from core import ...` 및 `from work_db import ...`는 호환 모듈에서 계속 지원합니다. 기존 게임 압축파일·모음집·개인 데이터의 저장 방식은 변경하지 않습니다.

남은 작업: 이미지 처리·AI 관련 모듈과 UI 대화상자 내 실제 서비스 호출을 더 분리할 예정입니다.
