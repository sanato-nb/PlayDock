# 공통 UI와 AI 품번 검토 개선

기준: 4b587821eac62c7273222d850d7416d2f42b7521. 사용자 요청에 따라 메인 레이아웃 및 스타일, 기존 기능, DB 스키마, 압축파일 및 설정 보존.

- Qt 본체 및 독립 이름 편집기의 공통 이벤트 필터에서 ToolTip 이벤트 차단. 아이콘 도구의 접근성 이름 및 hover 색상 유지. Windows 탐색기, 외부 브라우저, 설치기의 OS 기본 대화상자는 앱 밖 제어 대상이 아님.
- 공통 파일/폴더 선택창에 QStandardPaths 실제 바탕 화면, 다운로드, 문서, 사진, 음악, 동영상, 홈 경로를 추가하고 기존 바로가기 유지. 중복·없는 경로 제외. 기존 다크 제목줄, 필터, 선택, 저장 경로 유지.
- 설정/데이터 관리/설치기의 불필요한 버튼 말줄임표 제거. 처리 중 문구는 유지. 폴더 설정 RAR 표기 및 라이브러리/DB 설명 정리. 이번 요청에서 영문 버튼 한글화는 제외되어 기존 공통 버튼 문구는 변경하지 않음.
- AI JSON v1 유지. 단일 유력 후보의 공식 URL·ID·제목·근거를 needs_review로 보존, 불확실한 합본/복수 후보는 null. 근거 없는 후보, 기존 코드, 중복 및 잘못된 URL 차단. AI URL을 직접 접속하지 않음.
- 미확정 포함 선택 후보 공식 조회 → 실제 공식 작품명 확인 → 별도 체크 후 선택 등록. 조회만으로 게임 품번을 저장하지 않음(공식 작품 캐시는 저장 가능). 공식 ID 실재와 로컬 파일 정체 일치는 별개로 사용자 확인 필요.
- 수집 요약 줄 분리, 실제 연결 수/남은 품번 없는 게임 수 표시. 미확인 이유 표시 및 남은 대상의 프롬프트 재생성.
- 구형 상세 이름 편집기는 현재 기본 게임 관리 메뉴와 별개이며 metadata.open_title_editor, title_editor.py, title_editor_entry.py, 기존 빌드/테스트 호환 경로가 남아 있음. 삭제 시 기존 기능/호환 경로 손실 위험 때문에 유지. 이후 별도 승인으로 제거/통합 검토.
- 실제 Windows 모든 제목줄 및 고 DPI는 별도 검수. 기존 메인 UI 레이아웃·스타일 및 네이티브 제목줄 방식 변경 없음. main 병합 없음.
