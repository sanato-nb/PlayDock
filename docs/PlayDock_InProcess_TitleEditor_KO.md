# PlayDock 이름 설정 — 본체 한 개로 통합

기존 버전: PlayDock.exe에서 이름 관리 클릭 시 별도 PlayDock_TitleEditor.exe 실행.
통합 버전: 이름 설정은 PlayDock.exe에 포함된 Qt 창/대화상자로 직접 실행됩니다.

## 단일 게임 설정
- 라이브러리의 게임을 마우스 오른쪽 버튼으로 클릭 → '이 게임 이름 설정...'
- 선택한 게임 하나만 이름 관리자에 표시됩니다.
- 간편 이름 변경, 상세 기능, 작품 코드, 이전 이름 복원 기능을 유지합니다.
- 창을 닫으면 PlayDock 라이브러리의 표시 이름을 자동 새로고침합니다.
- 원본 ZIP/7z/RAR 압축파일과 설치 폴더는 변경하지 않습니다.

## 여러 게임 설정
- PlayDock 오른쪽 상단의 '이름 설정' 클릭.
- 체크박스로 여러 게임을 골라 변경 방법을 선택합니다.
- 직접 수정, 찾기/바꾸기, 품번 조회, 원본 복원, 이름 이력 되돌리기를 지원합니다.
- 선택된 대상 없이 자동으로 변경되지 않습니다.
- 미리보기에서 변경할 행을 체크하고, 최종 승인을 눌러 일괄 저장합니다.
- 기존 메타데이터 ZIP 백업과 원자적 변경/롤백을 유지합니다.

## 배포
- 이름 관리자용 별도 PlayDock_TitleEditor.exe는 빌드·설치하지 않습니다.
- 설치 마법사 PlayDock_Setup.exe와 제거 프로그램 PlayDock_Uninstall.exe는 유지합니다.
- 유효한 기존 설치를 업그레이드할 때 오래된 이름 관리자 실행파일/바로가기만 정리합니다.
- 기존 data 폴더, 개인 설정, 이미지, 작품 DB, 모음집, 게임 파일은 그대로입니다.
- 이전 버전에서 설치했던 이름 관리자 EXE가 없더라도 메뉴는 작동합니다.

## 안전
- 사용자별 DB·개인 경로·API 키는 공개 배포 파일에 포함하지 않습니다.
- 실제 게임 파일명 변경과 표시 이름 변경은 서로 다른 기능입니다.
- 이 버튼들은 PlayDock 라이브러리의 표시 제목만 수정합니다.
