# PlayDock v0.7.7 - **개인 데이터가 없는 공개 배포 만들기**

이 폴더는 Windows에서 EXE를 만들기 위한 소스 프로젝트입니다. **설치된 PlayDock 프로그램 폴더를 압축하여 배포하지 마세요.** 실제 사용 중인 설치 폴더의 `data/`에 모음집·수정한 게임 이름·설정·이미지 캐시·로컬 경로가 들어 있을 수 있습니다.

## 1. 배포용 ZIP을 안전하게 만드는 법

1. 이 프로젝트 ZIP을 Windows에 압축 해제합니다. 실행 중인 PlayDock는 종료해도 되고 유지해도 되지만, 기존 설치 폴더를 복사하지 마세요.
2. **`00_BUILD_WINDOWS_EXE.bat`** 을 실행합니다. 첫 실행 시 Python 또는 빌드 도구 설치가 필요할 수 있습니다.
3. 자동 테스트, EXE 빌드, 설치 프로그램 검증, 공개 ZIP 검사를 모두 통과하면 **`public_release/`** 폴더가 열립니다.
4. 여기 있는 **`PlayDock_Setup_v0.7.7.exe`** 또는 **`PlayDock_Public_v0.7.7.zip`** 만 사용자에게 배포합니다.

이전과 달리 `dist/`나 `%LOCALAPPDATA%\Programs\PlayDock`를 수동으로 압축할 필요가 없습니다.

## 2. 사용자가 받는 파일

- **`PlayDock_Setup_v0.7.7.exe`**: 권장 설치 파일. 일반 사용자는 이것만 받아도 됩니다.
- **`PlayDock_Public_v0.7.7.zip`**: 요청한 7-Zip 스크린샷과 비슷하게 실행 EXE·설치 EXE·설명서·**빈 `data/`**가 한눈에 보입니다. 압축 해제 후 Setup.exe로 설치하거나 직접 실행할 수도 있습니다.
- `PlayDock_Public_v0.7.7_검사결과.txt`: 빌드 결과 및 ZIP 내용 검사 결과.

공개 ZIP은 오직 아래의 파일만 포함합니다.

```text
PlayDock_Public_v0.7.7.zip
  data/                          (완전히 비어 있음)
  PlayDock.exe
  PlayDock_TitleEditor.exe
  PlayDock_Uninstall.exe
  PlayDock_Setup.exe
  PlayDock.install.json          (고정된 일반 초기화 표식; 개인 정보 없음)
  PlayDock_사용자설명서_v0.7.7.pdf
  처음사용법.txt
  SHA256SUMS.txt
```

**주의:** `PlayDock_Uninstall.exe`는 설치형 제거용이며, ZIP을 풀어 직접 실행한 버전의 제거에는 사용할 필요가 없습니다. 그런 경우 직접 푼 폴더를 지우면 됩니다(사용 후 생성된 `data`도 함께 제거되므로 백업을 고려하세요).

## 3. 개인정보 처리 원칙

- 사용자가 설치한 PlayDock 폴더, 사용자 게임 폴더, `AppData`의 기존 데이터, Windows 자격 증명 저장소, 환경 변수의 API 키를 **패키징 과정에서 읽거나 복사하지 않습니다**.
- 배포 ZIP에는 **설정 파일·게임 목록·모음집·이미지 캐시·API 키·개인 게임 폴더 경로가 일절 포함되지 않습니다.**
- ZIP 안의 빈 `data/`에 새 사용자의 데이터가 **처음 실행한 후** 생성됩니다. 설치형으로 실행하면 설치 마법사에서 폴더를 선택합니다.
- 설치형이 기존 PlayDock/Local Game Shelf 데이터가 있는 PC에서 실행되면, 업데이트 호환성을 위해 **그 PC의 기존 데이터를 이전**할 수 있습니다. 이는 배포 EXE에 데이터가 실려 있어서가 아닙니다.
- **네 PC에서 직접 실행해 '등록됨'으로 보이는 API 키는 Windows 자격 증명 저장소에 이미 있기 때문일 수 있습니다.** 이 값이 다른 PC로 전송되는 것은 아닙니다. 최초 사용자 환경의 정확한 검증은 Windows Sandbox나 새 Windows 사용자 계정에서 하세요.
- PyInstaller가 명시적으로 빌드한 EXE만 패키징합니다. 일반적인 하드코딩 키 패턴 검사를 수행하지만, 완전한 보안 감사나 악성 코드 검사를 대신하지는 않습니다.

## 4. GitHub Actions로도 배포 EXE 생성 가능

이 프로젝트를 **PlayDock 전용 GitHub 저장소**로 올린 뒤 `Actions → Build clean PlayDock public release → Run workflow`를 실행하면 GitHub Windows 실행 환경에서 빌드하여 `PlayDock_Public_v0.7.7` 결과물을 받을 수 있습니다. **네 PC에서 EXE를 빌드하거나 설치 폴더를 압축할 필요가 없습니다.** 개인 API 키나 `data` 폴더는 GitHub 저장소에 올리지 마세요.

## 5. 배포 전에 반드시 확인

1. `public_release`의 검사 결과에 실패 표시가 없는지 확인.
2. ZIP을 7-Zip으로 열어 `data/`가 **완전히 비었는지** 확인.
3. Windows Sandbox나 새 사용자 계정에서 Setup.exe, 앱 실행, 게임 폴더 설정, API 미등록 상태 테스트.
4. 최신 안티바이러스 검사 및 설치·제거 동작 확인. 코드 서명이 없는 EXE는 SmartScreen 경고가 뜰 수 있습니다.
5. `PlayDock`라는 상호를 쓰는 다른 서비스/프로그램과 혼동되지 않는지 공개 배포 전에 확인.

기존 개인 데이터 삭제나 정리는 **필요하지 않습니다**. 배포 파일을 별도로 깨끗하게 생성하는 것이 핵심입니다.
