요구사항 파일의 8종은 모두 실제 소스 import 경로 확인: PySide6-Essentials, py7zr, Pillow, keyring, pyzipper, send2trash, rarfile, ddgs. 선택적 기능 및 기존 호환 경로도 유지. 현재 제거할 런타임 패키지는 없음. 진입점, core, work_db, cache_management, data_management 등의 재노출 및 테스트·호환 이름은 본문에서 사용하지 않는 것만으로 삭제하지 않는다. detector 및 제거기에서 직접 사용하지 않는 표준 라이브러리 import 2개 제거.

원본 데이터 및 UI 디자인 유지. 작업 브랜치에서 소스 검증만 수행하며 EXE/배포/main 병합은 별도. 실제 사용자 Windows 화면과 실측 성능은 후속 검수 대상이다.
