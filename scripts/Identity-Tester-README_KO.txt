PlayDock 게임 정체 판독기 — Windows 검증판 사용 안내 (소스 v0.9, EXE 별도 수동 빌드)
================================================

[실행 방법]
1. 다운로드한 ZIP을 완전히 압축 해제합니다.
2. PlayDock-Identity-Tester.exe 파일을 실행합니다.
3. [압축파일 선택]에서 게임 ZIP, 7z, RAR 파일을 선택합니다.
   여러 파일을 한 번에 선택해도 됩니다.
4. [판독 시작]을 누릅니다.
5. 결과 표에서 파일을 선택하면 판정 근거와 미확인 사항을 볼 수 있습니다.
6. [결과 저장]에서 JSON 상세 보고서 또는 CSV 요약을 직접 저장할 수 있습니다.

[모드 안내]
- 인터넷 검색 + 1~6단계: DLsite / Steam / 웹 검색과 로컬 압축 근거 비교
- 인터넷 체크 해제: 4~5단계 내부 파일명·폴더 구조·README 제한 정보만 확인
  (오프라인에서는 공식 게임 정체 일치 여부를 확정하지 않습니다.)

[판정 설명]
- 일치 확인: 여러 명시적 근거가 서로 부합함. 진위나 안전성을 보증하지 않음
- 유력 후보: 외부 작품과 내부 제목/구성은 부합하지만 ID 근거 부족
- 확인 필요: 추가 근거 부족, 합본/DLC/패치 또는 암호 보호 파일
- 근거 충돌: 공식 ID 또는 강한 내부 제목 근거가 서로 다름
- 분류 불가: 게임 정체를 특정할 자료 없음

[안전과 개인정보]
- 이 검증판은 기존 PlayDock 본체와 별도 프로그램입니다.
- 원본 압축파일, 게임 실행파일, 라이브러리 DB를 수정하거나 실행하지 않습니다.
- 인터넷 모드는 사용자가 선택해 시작할 때만 실행합니다.
  외부로 전송되는 것은 추출한 게임 제목/작품 ID 검색어입니다.
  압축파일 바이트, 내부 README 전체 내용, PC의 전체 로컬 경로는 전송하지 않습니다.
- 사용자 게임 목록, 개인 데이터, 인증정보, API 키는 배포판에 포함되지 않습니다.
- 판독 결과 파일은 사용자가 [결과 저장]을 누른 위치에만 저장됩니다.
  JSON에는 선택한 파일명과 압축 내부 상대 경로가 포함될 수 있으므로
  개인 파일 목록을 공유할 때는 먼저 내용을 확인하세요.

[기능 제한]
- 암호화된 ZIP/7z/RAR은 파일명 검색만 수행하며 비밀번호를 입력받지 않습니다.
- RAR 압축 내부 파일 읽기에는 Windows의 별도 압축해제 도구가 필요할 수
  있습니다. 이 경우 읽지 못한 근거는 '미확인'으로 남깁니다.
- 솔리드 7z의 작은 내부 설정파일은 안전성을 위해 읽지 않을 수 있습니다.
- 1~6단계 엔진은 실험 버전이며 실제 압축파일 정답률은 아직 측정하지 않았습니다.
- 프로그램은 개발자 코드 서명이 되어 있지 않습니다.
  Windows SmartScreen 안내가 표시될 수 있으니 GitHub 출처와 파일을
  직접 확인한 후 실행하세요.

[0.5 검증판 - 수동 정확도 감사 기반 검색 품질 개선]
1. 압축파일명(별칭·상품코드·버전)과 내부 목록·설정 제목을 모두 모은
   뒤 검색어 정렬·중복 제거. 이름 먼저 검색하거나 내부 자료만 우선하지 않음.
2. 일반 실행기/폴더명(player/extracted/BepInEx/D3D12/licenses 등)은
   인터넷 검색 후보에서 제거. 소수 버전만 다른 실행파일도 같은 제목으로 정리.
   실제 시리즈 번호(게임 1/2 등)는 보존.
3. 명시적으로 한·일·영 이름을 병기한 공식 제목과 별도 단축명을 연결.
   같은 DLsite/Steam 공식 ID는 하나의 작품 후보로 통합.
   서로 다른 공식 상품 번호는 임의로 합치지 않음.
4. 빠른 모드에서 itch.io/Steam 개별 작품 페이지의 명확한 제목 일치가
   하나만 있어도 '웹 후보'로 보존하되 원본 압축파일 일치는 확정하지 않음.
   개발자 프로필·다른 작품 페이지는 제목만으로 연결하지 않음.
5. 동일한 조회를 한 배치에서 여러 번 수행하지 않도록 메모리 캐시.
   검색 서비스가 두 번 연속 오류를 내면 일반 제목 검색만 최대 20초
   일시 보류. 그 후 재시도, 명시적 RJ/Steam ID는 계속 확인.
   정밀 모드는 기존처럼 자세히 검색하는 용도.
6. 표의 '작품 조회'와 '내부 대조' 두 열을 분리:
   - 작품 조회: 공식 작품 발견/웹 후보/복수 후보/미발견/검색 오류
   - 내부 대조: 일치 확인/유력 후보/확인 필요/근거 충돌/분류 불가
   예: 공식 DLsite 상품이 확인돼도 압축 내용 근거가 없으면
       작품 조회=공식 작품 발견, 내부 대조=확인 필요.
7. 공식 상품이 별도 번역 패치나 DLC일 가능성이 있으면 유형을 기록하고
   본편과 동일 상품이라고 자동 연결하지 않음.
8. 상세 결과 JSON에 verification.catalog_status,
   verification.catalog_product_ids, verification.catalog_release_type,
   verification.local_identity_status, search_session, search_delta 추가.
   검색 사용량은 호출 횟수/캐시 재사용/장애 회피 횟수로 구분.
