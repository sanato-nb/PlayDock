PlayDock 게임 정체 판독기 v0.10.2-test — 독립 Windows 검증판

[시작 방법]
1. ZIP 안의 PlayDock-Identity-Tester.exe를 원하는 폴더에 압축 해제합니다.
2. EXE를 실행합니다. Python을 별도 설치할 필요가 없습니다.
3. "압축파일 선택"에서 ZIP / 7z / RAR 파일을 여러 개 선택합니다.
4. "판독 시작"을 누르고 온라인 조회에 동의합니다.
5. 기본 검색은 정밀 모드(최대 6개 검색어)입니다. 빠른 모드는 최대 3개입니다.
6. "전체 결과"와 "보류·미확인만" 탭을 확인합니다.
7. "JSON 저장"을 누르면 전체 결과와 unresolved 미확인 목록이 함께 저장됩니다.
8. "미확인 재검사"를 누르면 판독 보류 대상만 다시 검색합니다.
   파일 크기·수정시각이 같으면 이름·README 근거를 세션에서 재사용합니다.

[v0.10.2 검색 시간 및 정확도 개선]
- 압축파일명·최상위 폴더·주 EXE·README에서 이름/품번을 수집한 다음
  공식 품번이 있으면 먼저 직접 조회하고 로컬 게임명과 대조합니다.
- 공식 품번이 확인된 경우 같은 게임명의 불필요한 추가 인터넷 제목
  검색을 생략합니다. 품번이 2개 이상이면 각각 확인하고 보류합니다.
- 품번이 없는 작품은 제목 검색을 단일 짧은 웹 검색으로 제한합니다.
  첫 제목 검색이 네트워크 오류 또는 쿨다운이면 폴더/EXE 변형 이름을
  이어서 검색하지 않고 '검색 실패·재검사' 목록에 남깁니다.
- 비슷한 EXE/폴더 이름의 하이픈·공백 차이와 끝의 0.4.7,
  0.5.2-pc 같은 버전 태그는 중복 제목 검색에서 제외합니다.
- 공식 등록 상품명이 번역 패치임을 명시하면 본편과 동일하다고
  식별 확정하지 않고 유력 후보/확인 필요로 남깁니다.
- JSON의 search_queries는 계획한 검색어가 아니라 *실제로 시도한 검색어*만
  기록합니다. 검색 생략은 별도 판정 근거로 설명합니다.
- 사용자가 올린 11개 v0.10.1 JSON에서 품번 5회 성공에도 불필요한
  제목 검색 8회가 타임아웃을 발생시킨 문제를 바탕으로 수정했습니다.
- 11개 실사용 자료의 v0.10.2 재검사는 아직 수행되지 않았습니다.

[v0.10.1 추가 규칙 — 내부 폴더 첫 화면만 참고]
- 압축파일을 처음 열었을 때 직접 보이는 1단계 최상위 폴더명만
  게임 이름·품번의 내부 폴더 후보로 수집합니다.
- 하위 경로의 plugins/codec, audio/bgm, img/characters, effects/Model,
  BepInEx/config 등은 폴더명 검색어로 절대 사용하지 않습니다.
- 첫 화면에 보이더라도 audio, css, data, effects, fonts, icon, img,
  js, locales, save, swiftshader, www, resources 같은 공통 폴더는 제외합니다.
- 게임명처럼 보이는 최상위 폴더만 보조 후보가 될 수 있습니다.
- EXE와 README는 기존의 별도 안전 규칙으로 제한 검사합니다.
- 압축파일 이름이 검색 1순위이고, 품번은 있으면 함께 조회합니다.

[v0.10에서 수집하는 정보 — 딱 2가지]
- 게임 이름: 압축파일명 → 최상위 폴더명 → 주 EXE명 → README 명시 라벨.
- 선택적 품번·상품 ID: RJ / BJ / VJ / EJ 번호, 명시된 Steam App ID.
- 여러 주요 EXE가 서로 다른 이름이면 임의로 하나를 고르지 않습니다.
- python.exe / CrashReportClient.exe / createdump.exe / updater 등은
  주 게임 실행파일명으로 검색하지 않습니다.
- README는 최대 2개 파일, 파일당 최대 32KiB만 제한적으로 읽으며
  Title / Game Name / 게임명 / 作品名 / 품번 / 品番 / DLsite Code 등
  라벨이 있는 명시 값만 사용합니다. README 원문을 웹에 전송하지 않습니다.
- ZIP/7z/RAR의 *파일 목록 이름*만 확인하며 게임 EXE 본문을 읽거나
  실행하지 않습니다. 7z 솔리드 압축의 README는 안전상 건너뛸 수 있습니다.
- 암호화/암호상태 미확인 압축파일은 오직 압축파일명만 사용합니다.

[정체 판정]
- 공식 작품 식별: 외부 공식 상품명과 로컬의 이름 및 품번/추가 이름 단서가
  일치할 때. *실제 파일 진위 인증은 아님*.
- 유력 후보: 공식 작품을 찾았지만 로컬 이름/품번 근거가 충분하지 않음.
- 복수 후보: 서로 다른 상품의 공식 코드 또는 여러 후보 존재.
- 정체 미확인: 작품 후보를 찾지 못함.
- 검색 실패·재검사: 외부 통신 오류 또는 검색 생략.
- "유력 후보" 이상도 로컬 파일 내용과 실제 동일한지는 확인하지 않았습니다.
- 정체를 찾지 못한 파일은 별도 탭과 JSON의 unresolved 배열에 남깁니다.

[지금은 검사하지 않는 정보]
- 게임 엔진, 버전, 한글화/번역 패치, DLC, 압축파일 크기 및 게임 파일 내용.
- 이런 세부 검사는 게임 정체가 확인된 *이후* 별도 기능으로 개발할 대상입니다.

[개인정보·안전]
- 공개 GitHub에 개인 게임 목록·검사 JSON·파일의 전체 로컬 경로·API 키를
  업로드하지 않습니다. 결과는 사용자가 JSON 저장을 선택한 곳에만 기록합니다.
- 인터넷에는 이름과 품번 검색어만 전송합니다.
- 배포용 EXE는 사용자 계정·사용자 파일·개인 캐시·API 키 없이 생성됩니다.
- SmartScreen 경고가 있을 수 있습니다. 출처가 불확실하면 실행하지 마세요.
- EXE 동작 확인: --self-test (네트워크/GUI 없이 자가 검사 후 종료).

[주의]
공식 카탈로그 작품 발견이나 이름/품번 일치는 실제 압축파일의 내용·진위·
언어·버전을 인증하지 않습니다. 자동 PlayDock DB 연결/파일 수정은 하지 않습니다.
사용자 정답 검수 없이 정확도 비율을 산정할 수 없습니다.
