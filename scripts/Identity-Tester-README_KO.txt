PlayDock 게임 정체 판독기 — Windows 검증판 0.4
================================================

[실행 방법]
1. 다운로드한 ZIP을 완전히 압축 해제합니다.
2. PlayDock-Identity-Tester.exe 파일을 실행합니다.
3. [압축파일 선택]에서 게임 ZIP, 7z, RAR 파일을 선택합니다.
   여러 파일을 한 번에 선택해도 됩니다.
4. [판독 시작]을 누릅니다.
5. 결과 표에서 파일을 선택하면 판정 근거와 미확인 사항을 볼 수 있습니다.
6. [결과 저장]에서 JSON 상세 보고서 또는 CSV 요약을 직접 저장할 수 있습니다.

[모드 안내]
- 인터넷 검색 + 1~6단계: DLsite / Steam / 웹 검색과 로컬 압축 근거 비교
- 인터넷 체크 해제: 4~5단계 내부 목록/설정파일 검사만 실행
  (오프라인에서는 공식 게임 정체 일치 여부를 확정하지 않습니다.)

[판정 설명]
- 일치 확인: 여러 명시적 근거가 서로 부합함. 진위나 안전성을 보증하지 않음
- 유력 후보: 외부 작품과 내부 제목/구성은 부합하지만 ID 근거 부족
- 확인 필요: 추가 근거 부족, 합본/DLC/패치 또는 암호 보호 파일
- 근거 충돌: 공식 ID 또는 강한 내부 제목 근거가 서로 다름
- 분류 불가: 게임 정체를 특정할 자료 없음

[안전과 개인정보]
- 이 검증판은 기존 PlayDock 본체와 별도 프로그램입니다.
- 원본 압축파일, 게임 실행파일, 라이브러리 DB를 수정하거나 실행하지 않습니다.
- 인터넷 모드는 사용자가 선택해 시작할 때만 실행합니다.
  외부로 전송되는 것은 추출한 게임 제목/작품 ID 검색어입니다.
  압축파일 바이트, 내부 README 전체 내용, PC의 전체 로컬 경로는 전송하지 않습니다.
- 사용자 게임 목록, 개인 데이터, 인증정보, API 키는 배포판에 포함되지 않습니다.
- 판독 결과 파일은 사용자가 [결과 저장]을 누른 위치에만 저장됩니다.
  JSON에는 선택한 파일명과 압축 내부 상대 경로가 포함될 수 있으므로
  개인 파일 목록을 공유할 때는 먼저 내용을 확인하세요.

[기능 제한]
- 암호화된 ZIP/7z/RAR은 파일명 검색만 수행하며 비밀번호를 입력받지 않습니다.
- RAR 압축 내부 파일 읽기에는 Windows의 별도 압축해제 도구가 필요할 수
  있습니다. 이 경우 읽지 못한 근거는 '미확인'으로 남깁니다.
- 솔리드 7z의 작은 내부 설정파일은 안전성을 위해 읽지 않을 수 있습니다.
- 1~6단계 엔진은 실험 버전이며 실제 압축파일 정답률은 아직 측정하지 않았습니다.
- 프로그램은 개발자 코드 서명이 되어 있지 않습니다.
  Windows SmartScreen 안내가 표시될 수 있으니 GitHub 출처와 파일을
  직접 확인한 후 실행하세요.

[기술 정보]
Windows 10/11 64비트 · Python 설치 없이 EXE 실행
독립 실험 브랜치: experiment-dlsite-game-detector-20261117

문제 제보 시 상세 JSON 결과를 첨부할 수 있지만 개인정보가 담겨 있는지 확인하세요.

[0.2 검증판 변경 내용]
- 진행바를 화면 위쪽으로 이동해 결과/상세 목록에 가리지 않도록 했습니다.
- 검사 완료 파일 개수 / 전체 파일 개수와 전체 단계 기준 진행률(%) 표시.
  예: 3/128개 완료, 전체 약 2.5%. 이 숫자는 예상 소요시간이 아닙니다.
- 현재 검사 중인 파일과 1~6단계의 상세 작업 표시.
  인터넷 검색은 응답 시간에 따라 같은 단계에 오래 머무를 수 있습니다.
- 한국어/일본어 게임명으로 공식 제목을 못 찾은 경우,
  이미 검색한 웹 결과에서 영문 제목이 병기되어 있는지 검사합니다.
  서로 다른 도메인 2곳 이상이 동일 영문 표기를 보여줘도
  '게임 후보/확인 필요'로만 표시하며 공식 정체 확정은 아닙니다.
- 선택한 결과에서 웹 검색 단계별 이유와 내부 제목 후보를 추가 표시합니다.

[황성의 빅토리아스 사례]
- 현지어 제목 표기: 황성의 빅토리아스
- 웹 자료에서 병기된 영문 제목 후보: Radiant Victorias
- 공개 자료의 작품 코드 후보: RJ01038880 / Steam App ID 2652480
- 주의: 실제 로컬 7z 내부와 공식 원본 사이의 동일성은 아직 미검증.
  온라인 검색 차단/빈 검색 결과라면 이 버전에서도 '분류 불가'일 수 있습니다.

[0.3 검증판 - 내부 근거 먼저, 인터넷 검색은 나중에]
- 비암호화 파일: 압축파일명에서 제목·작품 코드만 분리 → 암호 확인 →
  내부 전체 파일 목록 → 제한된 작은 설정파일·README 내용 확인 →
  모아둔 제목/작품 ID를 우선순위대로 인터넷 통합 검색 →
  모든 자료와 공식 작품 후보 교차검증.
- 암호화된 파일 또는 암호 상태 확인 불가 파일: 내부를 읽지 않음.
  파일명 검색만 진행. 검색 실패 시 분류 불가 정책 유지.
- 진행바는 새로운 실행순서 1→3→4→5→2→6에 따라 표시하며
  검사 완료 파일 수/전체 개수/단계 기준 퍼센트를 유지.
- 내부의 공통 실행파일(알림 도우미/번역기 보조 실행기 등)과 공통 폴더
  이름(locales/css/audio/swiftshader 등)은 검색 후보에서 제외.
- 게임 엔진 설정의 기본 프로젝트명은 출시 제목과 같은 '강한 증거'로
  인정하지 않음. 서로 다른 정식 작품 ID 충돌은 그대로 차단.
- 공식 작품명이 일본어/영어를 명시적으로 병기했을 때
  그중 하나의 명시적 게임명과 비교 가능. 임의 번역/유사도는 인정하지 않음.
- 검색 서비스 오류는 실제 게임 부재와 구분. 부분 메타데이터나
  압축파일명과 내부 실행파일명 일치만 있는 경우에도 '확인 필요'로 보관.
- 새로운 버전에서도 게임 자동 등록·기존 파일·PlayDock DB 변경 없음.

[주의]
- 작품명/작품 코드/내부 게임 파일 일치도는 어디까지나 판정 근거.
  실제 배포물의 원본 여부를 확인하거나 안전한 실행을 보증하지 않습니다.
- 기존 v0.1 JSON의 결과는 자동으로 고쳐지지 않습니다.
  수정 후 새 EXE로 같은 압축파일을 다시 검사해야 변경점이 반영됩니다.

[0.4 검증판 - 파일명과 내부 근거 통합 수집 및 속도 개선]
- 정확한 처리 개념: 압축파일 이름의 작품명/품번/별칭과 압축 내부의
  파일명/작품 코드/설정파일 제목/엔진 단서를 모두 수집합니다.
  두 출처를 합쳐 하나의 검색 계획을 만든 후에만 인터넷 조회합니다.
  내부 분석 결과를 파일명보다 무조건 우선하지 않습니다.
- 암호화/암호 상태를 확인할 수 없는 파일만 이름 기반 검색만 수행합니다.
- GUI [빠른 검색]은 기본 켜짐: 파일당 최대 3개 검색어,
  제목당 단일 일반 웹 요청/제한 시간 6초 설정, DLsite 중복 제목 조회 생략.
  명시적 작품번호는 공식 등록번호 조회를 유지합니다.
- [빠른 검색] 체크를 해제하면 기존처럼 최대 6개 검색어로
  자세히 검색합니다. 신뢰도 미확정 파일만 다시 검사할 때 사용하세요.
- 공식 품번 확인 후 약한 파일명/폴더명 재검색은 생략합니다.
  다른 명시적 코드와 강한 내부 설정 제목의 비교는 유지합니다.
- 압축 암호 상태는 한 파일당 검사한 결과를 목록 분석과 메타데이터
  분석에 재사용해 헤더를 불필요하게 여러 번 열지 않습니다.
- RAR 백엔드 문제는 프로그램 전체 오류 대신 내부 메타데이터 판독
  제한으로 남깁니다. RAR 도구가 없어도 읽을 수 없는 부분은 미확인입니다.
- 개별 파일의 실제 처리 초 단위를 상세 화면/결과 JSON의
  analysis_seconds에 기록합니다. 숫자는 측정값이며 예상 시간이 아닙니다.
- 기존 결과와 새 결과를 비교하려면 v0.4로 같은 파일을 다시 검사하세요.
- 검색 제공자가 느리거나 네트워크에서 막혀 있다면 빠른 모드라도
  지연되거나 정체가 확인되지 않을 수 있습니다.

[개인정보 및 안전]
- 원본 압축파일은 수정/해제/게임 실행되지 않습니다.
- 검색에는 선택한 후보 게임명·공식 품번만 전송합니다.
- GUI 결과 JSON은 사용자 본인이 지정한 위치에만 저장합니다.
- main 브랜치/PlayDock 라이브러리·DB에 자동 반영하지 않습니다.
