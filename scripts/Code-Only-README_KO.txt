PlayDock — DLsite 품번 확인기 (코드 전용 간소화판)

실행파일: PlayDock-DLsite-Code-Checker.exe

사용 방법
1. 압축파일(ZIP/7z/RAR)을 여러 개 선택하거나 폴더를 선택합니다.
   파일 선택 대신 RJ123456 / VJ123456 / BJ123456 / EJ123456 형태의
   품번을 입력창에 줄별로 직접 입력해도 됩니다.
2. [품번 확인 시작]을 누르면 파일명에 있는 품번만 찾아 공식 DLsite 작품
   HTML 페이지에서 해당 품번의 공식 작품명을 확인합니다.
3. 품번 없는 파일은 인터넷에 접속하지 않고 [품번 없음 · 건너뜀]으로 표시됩니다.
   이름 검색·원제 추측·Bing RSS·DDGS·Google 검색을 하지 않습니다.
4. 하나의 압축파일 이름에 품번이 여러 개 있으면 각각 확인합니다.
   동일 품번이 여러 파일에 있으면 같은 실행 배치에서는 조회 결과를 재사용합니다.
5. 결과를 더블클릭하면 확인된 DLsite 공식 작품 페이지가 열립니다.
   [CSV 저장]/[JSON 저장]으로 조회 내역을 저장할 수 있습니다.

주의
- 네트워크 요청에는 품번만 사용하며 로컬 폴더 전체 경로를 보내지 않습니다.
- 압축파일의 내용은 열거나 압축 해제하지 않습니다.
- HTTP 접근제한, 성인인증 페이지, 사이트 장애로 공식 이름을 확인하지 못하면
  [조회 불가]로 기록합니다. 미등록 판정을 하지 않습니다.
- 품번과 작품명 조회는 게임 실행파일과 동일한 제품이라는 증명이 아닙니다.
- 사이트의 일반 공개 HTML을 조회하며 별도 유료 API 또는 API 키가 필요하지 않습니다.
- 사용자 파일명과 게임 목록을 GitHub 배포 파일에 포함하지 않습니다.
- 한 번에 최대 1000개 파일명/입력을 처리하며 중간에 중단할 수 있습니다.
- 기존의 '이름 → 품번 자동 검색' 기능과 DDGS/Bing RSS는 이 EXE에서 제거했습니다.
  기존 연구용 소스는 이전 실험 기록으로 GitHub에 남아 있지만 배포판에 연결되지 않습니다.
- 설치 마법사/자동 업데이트/플레이시간 추적/통계 대시보드가 없습니다.

빌드와 회귀검사: GitHub Actions -> DLsite 코드 전용 Windows 빌드 (수동 실행)
