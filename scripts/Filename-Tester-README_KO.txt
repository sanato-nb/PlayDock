PlayDock 게임 정체 판독기 v0.11.4-test — 압축파일 이름만 검사

[이번 버전의 목적]
인터넷 제목 검색이 불안정하여 최소 기능부터 다시 검증합니다.
압축파일을 열지 않고 오직 ZIP/7z/RAR *파일명 한 줄*에서
① 게임명 ② 선택적 품번(RJ/BJ/VJ/EJ, Steam App ID)만 추출합니다.
EXE, README, 하위 폴더, 압축 파일 목록, 파일 내용은 전혀 검사하지 않습니다.

[사용 방법]
1. PlayDock-Identity-Tester.exe 실행 (Python 설치 불필요).
2. 압축파일 선택 → 실제 파일을 지정할 수 있습니다. 그러나 파일명만 읽습니다.
3. 또는 "파일명 붙여넣기" → 실제 파일이 없어도 이름 여러 줄을 시험할 수 있습니다.
4. "인터넷 판독 시작" 클릭 → 동의 후 검색. 기본적으로 추가 옵션은 없습니다.
5. 왼쪽 전체 결과 / 미확인·보류 탭과 근거 상세를 확인합니다.
6. "JSON 저장" → files와 unresolved 배열로 결과 저장.
7. 미확인 항목은 "미확인 재검사" 버튼으로 다시 검색할 수 있습니다.

[v0.11.4 검색 결과 정확도 개선]
- 129개 v0.11.3 실제 검사에서 웹 이름 단서 17개, 검색 장애 18개,
  정체 미확인 6개. 웹 단서 중 제작자 계정·다른 챕터·다른 작품
  제목 일부만 겹치는 URL을 게임 정체 후보로 선택하던 문제가 확인됨.
- **DDGS 먼저 조회, 관련 게임 결과가 없거나 검색 실패 시 Bing RSS 보조.**
  결과가 있어도 작품 이름·URL 경로가 맞지 않으면 자동 채택하지 않음.
- 제작자 itch.io 홈은 작품 페이지가 아니므로 후보에서 제외.
  같은 게임에서도 작품 홈 > 구매 페이지 > 데모/개발일지 > 기사 순서로 평가.
- 제목이 짧을 때 다른 작품 제목 일부에 포함된 글자만으로 일치 처리 금지.
  Chap.1과 Chapter 2·3 등 서로 다른 작품 편/시리즈 번호 구분.
- 소유격/띄어쓰기처럼 Elena's Story와 elenastory 유형의 이름 표기를
  대조할 수 있도록 하고, '+'가 붙은 합본형 이름을 하나의 임의
  시리즈로 확정하지 않고 전체 제목 단서로만 비교.
- Steam URL에 작품 이름이 맞아도 **Steam 공식 상품명과 유형**을 직접
  확인해 둘 다 일치할 때만 공식 상품명 일치로 분류.
- 공식 상품 제목이 파일명과 다른 URL은 웹 후보로 다시 채택하지
  않고 제외 사유와 공식 제목을 결과 JSON에 기록.
- 제목 검색 실패 시 DDGS/Bing RSS 중 어떤 제공자가 어떤 오류를
  냈는지 JSON 및 상세 화면에서 확인할 수 있음.
- 검색 시간과 실제 인식률 개선은 v0.11.4 재검사 전까지 미측정.
  본판도 압축파일 내부 파일, EXE, README, 게임 버전/패치 정보는 미검사.

[v0.11.3 검색 결과 관련성 개선]
- 이전 129개 검사에서 품번 없는 39개를 Bing RSS로 검색했으나
  39건 모두 일반 웹 검색 결과를 판독하지 못했습니다.
- 실제 Bing RSS 결과가 6건 존재하기만 하면 다른 검색을 중지했습니다.
  '6월의 너와 나'에 숫자 6의 위키백과, 'BunnyHero'에 중국 자동차 글,
  'BUZAMA 2'에 오사카성 여행 글을 받은 것이 문제였습니다.
- 이제 제목 전체의 일치 여부, 게임 관련 문맥, 공식 판매 페이지 여부를
  검사해 무관한 Bing RSS 결과는 버리고 DDGS로 다시 검색합니다.
- Bing 결과에 실제 공식 게임 판매 페이지가 있으면 불필요한 DDGS 검색을
  생략합니다. 일반 게임 기사만 발견했다면 DDGS로 공식 페이지를 더 탐색합니다.
- REC·PASEC 등 짧은 게임 이름도 단어 경계+게임 문맥/배포 페이지
  확인을 거쳐 미검증 웹 후보로 보여줄 수 있습니다.
- JSON 및 상세 화면에서 검색 제공자별 '전체 결과/관련 결과/제외 결과',
  제외한 검색 결과 예시와 응답시간을 확인할 수 있습니다.
- 추가 검색을 수행하므로 품번 없는 게임은 이전보다 시간이 더
  걸릴 수 있습니다. 각 제목의 자식 검색 워커 13초 제한을 유지합니다.
- 실제 129개 정확도 개선 여부는 v0.11.3 재검사 JSON으로 검증해야 합니다.

[v0.11.2 검색 정확도/진단 보강]
- 실제 v0.11.1 사용자의 129개 검사에서 품번 없는 39개가 모두
  '정체 미확인'으로 표시됐지만, 웹 검색 원본 결과가 JSON에 없어
  검색 결과 자체가 빈 것인지 프로그램 필터가 버린 것인지 구분 불가.
- 이제 게임명 검색에서 Bing RSS와 DDGS 각각의 응답 결과 수·시간과
  실제 웹 결과 제목·URL 최대 6건을 JSON/선택 상세 화면에 보존합니다.
- 게임명과 제목이 연결되는 게임 관련 웹페이지는 '웹에서 게임명 단서 발견'
  상태로 표시합니다. 이것은 원본 게임 확인이 아닌 미검증 단서입니다.
- 댓글/프로필/검색 페이지, 관계없는 제목은 여전히 후보에서 제외합니다.
- 공식 작품 코드와 제목이 직접 확인된 경우에만 공식 상품 일치로 분류합니다.
- 검색 공급자 모두 결과 0건이면 미확인 상태로 보존합니다.
- 다시 129개로 검사해 반환 결과와 채택/제외 여부를 비교해야 실제
  정확도 향상을 확인할 수 있습니다.

[v0.11.1 핵심 변경]
- 이전 프로그램에서 느린 DDGS 검색을 8초 기다린 뒤에도 검색 스레드가
  종료되지 않아 다음 32개 파일이 LookupBusy로 연쇄 실패했습니다.
- 이번 판은 게임명 검색을 별도 프로세스에서 실행하고 약 13초
  내에 끝나지 않으면 그 프로세스를 강제 종료합니다.
  이후 게임명 검색은 다시 시작할 수 있습니다.
- 웹 검색은 Bing RSS를 우선 조회한 뒤 필요 시 DDGS를 대체 검색으로
  사용합니다. 두 검색 제공자 모두 차단되면 '검색 장애'로 남깁니다.
- 품번만 있거나 다국어 제목 비교가 어려워도 해당 품번의 공식 상품을
  실제로 조회했다면 '품번으로 공식 상품 발견 · 제목 미검증'으로
  별도 표시합니다. 실제 게임 파일의 내용·진위 인증은 여전히 아닙니다.
- GUI와 JSON에는 공식 제목 일치/품번 공식 상품 발견/미확인 등을 구분합니다.
- 이전 129개 검사에서 나타난 문제가 해결됐는지는 새 JSON으로 비교해야 합니다.

[검색 방식]
- 품번 또는 Steam App ID가 **있으면** 해당 공식 등록 데이터를 직접 조회합니다.
  상품번호를 확인할 수 없는 경우, 오류와 함께 미확인으로 남깁니다.
  임의의 게임명 반복 검색은 하지 않습니다.
- 품번이 **없으면** 게임 이름으로 짧은 웹 검색 1회만 시도합니다.
  나온 DLsite 공식 작품 링크는 코드/공식 제목을 제한적으로 재확인합니다.
  Steam 공식 작품 링크도 공식 앱 데이터로 제한 검증합니다.
  itch.io 검색 결과는 작품 페이지 후보까지만 인정하고 자동 확정하지 않습니다.
- 공식 DLsite·Steam 조회의 제한시간은 기존과 같고, 제목 웹 검색은
  독립 프로세스당 약 13초로 제한합니다. 초과 시 워커를 종료하고
  다음 파일의 검색을 새로 시작합니다. PyInstaller 실행파일 초기화
  시간과 운영체제 상태에 따라 실제 소요시간은 달라질 수 있습니다.
- 게임명을 같게 찾았더라도 실제 압축파일의 정체·진위를 확인한 것은 아닙니다.

[판정]
- 공식 상품명 일치: 공식 상품번호/명칭/게임 유형과 파일명 일치
- 품번으로 공식 상품 발견: 등록 코드는 확인되었으나 파일명과
  공식 제목의 언어/이름 일치는 미검증. 실제 압축 내용도 미확인.
- 후보: 공식 상품명 불일치, 비게임·번역 패치, 미검증 작품 링크
- 복수 상품 후보: 여러 공식 상품이 있음
- 웹 단서 발견: 검색 결과에 게임 이름·문맥 단서가 있으나 공식 미인증
- 정체 미확인: 검색 0건 또는 결과는 받았으나 검증 후보 없음
- 검색 장애: 타임아웃·통신 문제로 검증 불가. 게임이 없다는 뜻이 아님

[보안·개인정보]

- 인터넷에는 게임명과 상품번호만 전달합니다.
- 사용자가 저장한 개인 결과는 공개 GitHub에 올리지 않습니다.
- 기존 PlayDock 본체, 게임 파일, 사용자 라이브러리를 변경하지 않습니다.
