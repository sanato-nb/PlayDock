PlayDock 게임 파일명 전용 검색기 v0.11.7-no-api-test
========================================================

[핵심: API 호출 자체를 하지 않는 독립 Windows 검색기]
- 추가 계정, 토큰, API 키, 유료 검색 서비스 필요 없음.
- Serper/Google 검색 API, Steam JSON API, DLsite JSON API를 사용하지 않습니다.
- 검색은 공개 웹페이지의 HTML만 읽습니다. HTTP(S) 웹 접속은 발생합니다.
- 압축파일(zip/7z/rar)은 열지 않습니다. 파일명에서 제목과 등록번호만 읽습니다.
- 로컬 전체 경로나 압축파일 내부 목록은 검색 서비스로 보내지 않습니다.

[사용 방법]
1. ZIP 안의 PlayDock-Identity-Tester.exe를 실행합니다 (Python 설치 불필요).
2. '압축파일 선택' 또는 '파일명 붙여넣기'로 검사 대상을 추가합니다.
3. 'API 없는 웹 검색 시작' 버튼을 누르면 공개 사이트에 작품명/ID를 조회합니다.
4. 판독 근거, 공급자별 오류와 검사 시간을 확인합니다.
5. 'JSON 저장'으로 검사 결과를 PC에 저장합니다.
6. 검색 장애/미확인 항목은 '미확인 재검사'로 다시 시도할 수 있습니다.

[실제 조회 방식]
- 제목 검색: DuckDuckGo 일반 HTML / itch.io 검색 페이지 /
  Mojeek 일반 HTML / Steam 상점 검색 HTML. 적합한 작품 페이지 발견 시 종료합니다.
- 품번 있음: DLsite 개별 상품 HTML을 최대 2개 카테고리에서 조회합니다.
- Steam App ID: Steam 상점의 /app/숫자/ 일반 HTML 페이지를 조회합니다.
- 검색 결과에서 발견된 상품번호도 개별 공개 HTML 페이지와 대조합니다.
- robots/이용조건/차단/캡차를 우회하지 않습니다. 반복 요청을 남발하지 않습니다.
- 사이트의 HTML 구조 변경이나 성인/연령 확인으로 검색이 막힐 수 있습니다.
- HTML만으로 게임 유형을 확인할 수 없다면 '공식 일치'로 단정하지 않습니다.
- 검색 사이트가 응답하지 않으면 '검색 장애'로 남깁니다. 게임 부재가 아닙니다.

[이전 v0.11.6 실사용 비교: 신 버전 성능 아님]
- 동일 129개 파일명: API 키 없는 DDGS/Bing 결과 검색 장애 38건,
  외부 유료 검색 서비스를 사용했던 결과 검색 장애 8건.
- 당시 품번 없는 파일 39개는 DDGS 39건 모두 오류. Bing RSS는 1건만 관련 결과.
- 따라서 v0.11.7은 기존 DDGS/Bing 대신 독립 HTML 검색을 시험합니다.
- 실제 v0.11.7 온라인 적중률은 본인 PC 재검사 전까지 미측정입니다.

[중요한 한계]
- 검색된 작품명 또는 상품번호는 파일의 내부 내용/버전/언어/정품 여부를
  증명하지 않습니다.
- 작품번호 없는 파일명, 별칭/번역 제목, DLC/모드/패치는 추가 확인이 필요합니다.
- 본 독립 테스트판은 PlayDock 게임 목록/DB와 연동되지 않으며 원본을 변경하지 않습니다.
- 생성된 개인 검사 결과 JSON은 비공개로 보관하십시오.
