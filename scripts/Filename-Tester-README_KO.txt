PlayDock 게임 정체 판독기 v0.11.1-test — 압축파일 이름만 검사

[이번 버전의 목적]
인터넷 제목 검색이 불안정하여 최소 기능부터 다시 검증합니다.
압축파일을 열지 않고 오직 ZIP/7z/RAR *파일명 한 줄*에서
① 게임명 ② 선택적 품번(RJ/BJ/VJ/EJ, Steam App ID)만 추출합니다.
EXE, README, 하위 폴더, 압축 파일 목록, 파일 내용은 전혀 검사하지 않습니다.

[사용 방법]
1. PlayDock-Identity-Tester.exe 실행 (Python 설치 불필요).
2. 압축파일 선택 → 실제 파일을 지정할 수 있습니다. 그러나 파일명만 읽습니다.
3. 또는 "파일명 붙여넣기" → 실제 파일이 없어도 이름 여러 줄을 시험할 수 있습니다.
4. "인터넷 판독 시작" 클릭 → 동의 후 검색. 기본적으로 추가 옵션은 없습니다.
5. 왼쪽 전체 결과 / 미확인·보류 탭과 근거 상세를 확인합니다.
6. "JSON 저장" → files와 unresolved 배열로 결과 저장.
7. 미확인 항목은 "미확인 재검사" 버튼으로 다시 검색할 수 있습니다.

[v0.11.1 핵심 변경]
- 이전 프로그램에서 느린 DDGS 검색을 8초 기다린 뒤에도 검색 스레드가
  종료되지 않아 다음 32개 파일이 LookupBusy로 연쇄 실패했습니다.
- 이번 판은 게임명 검색을 별도 프로세스에서 실행하고 약 8.5초
  내에 끝나지 않으면 그 프로세스를 강제 종료합니다.
  이후 게임명 검색은 다시 시작할 수 있습니다.
- 웹 검색은 Bing RSS를 우선 조회한 뒤 필요 시 DDGS를 대체 검색으로
  사용합니다. 두 검색 제공자 모두 차단되면 '검색 장애'로 남깁니다.
- 품번만 있거나 다국어 제목 비교가 어려워도 해당 품번의 공식 상품을
  실제로 조회했다면 '품번으로 공식 상품 발견 · 제목 미검증'으로
  별도 표시합니다. 실제 게임 파일의 내용·진위 인증은 여전히 아닙니다.
- GUI와 JSON에는 공식 제목 일치/품번 공식 상품 발견/미확인 등을 구분합니다.
- 이전 129개 검사에서 나타난 문제가 해결됐는지는 새 JSON으로 비교해야 합니다.

[검색 방식]
- 품번 또는 Steam App ID가 **있으면** 해당 공식 등록 데이터를 직접 조회합니다.
  상품번호를 확인할 수 없는 경우, 오류와 함께 미확인으로 남깁니다.
  임의의 게임명 반복 검색은 하지 않습니다.
- 품번이 **없으면** 게임 이름으로 짧은 웹 검색 1회만 시도합니다.
  나온 DLsite 공식 작품 링크는 코드/공식 제목을 제한적으로 재확인합니다.
  Steam 공식 작품 링크도 공식 앱 데이터로 제한 검증합니다.
  itch.io 검색 결과는 작품 페이지 후보까지만 인정하고 자동 확정하지 않습니다.
- 공식 DLsite·Steam 조회의 제한시간은 기존과 같고, 제목 웹 검색은
  독립 프로세스당 약 8.5초로 제한합니다. 초과 시 워커를 종료하고
  다음 파일의 검색을 새로 시작합니다. PyInstaller 실행파일 초기화
  시간과 운영체제 상태에 따라 실제 소요시간은 달라질 수 있습니다.
- 게임명을 같게 찾았더라도 실제 압축파일의 정체·진위를 확인한 것은 아닙니다.

[판정]
- 공식 상품명 일치: 공식 상품번호/명칭/게임 유형과 파일명 일치
- 품번으로 공식 상품 발견: 등록 코드는 확인되었으나 파일명과
  공식 제목의 언어/이름 일치는 미검증. 실제 압축 내용도 미확인.
- 후보: 공식 상품명 불일치, 비게임·번역 패치, 미검증 작품 링크
- 복수 상품 후보: 여러 공식 상품이 있음
- 정체 미확인: 해당 검색에 확인할 수 있는 출처 없음
- 검색 장애: 타임아웃·통신 문제로 검증 불가. 게임이 없다는 뜻이 아님

[보안·개인정보]
- 소스/배포 ZIP에는 개인 게임 목록·파일 경로·검사 JSON·API 키가 없습니다.
- 인터넷에는 게임명과 상품번호만 전달합니다.
- 사용자가 저장한 개인 결과는 공개 GitHub에 올리지 않습니다.
- 기존 PlayDock 본체, 게임 파일, 사용자 라이브러리를 변경하지 않습니다.
- 실행파일 검증: PlayDock-Identity-Tester.exe --self-test
