PlayDock — 품번 → 공식 이름 확인 → 결과 TXT 하나로 AI 인계
Windows 10/11 콘솔 실행파일: PlayDock-ID-Scan-And-Prompt.exe

이 프로그램의 역할
  ZIP / 7z / RAR 압축파일의 파일명만 읽어
  DLsite(RJ/VJ/BJ/EJ) 우선, 실패하면 명시된 Steam App ID로
  공식 작품명을 조회합니다. 제목 자동 검색이나 AI API는 사용하지 않습니다.
  마지막 파일까지 검사가 끝난 후 단 하나의 TXT를 생성합니다.

사용법
  1. EXE를 실행합니다. 시작 옵션을 고릅니다:
     1 = 품번 검사만 (기본값)
     2 = 품번만 있는 파일을 공식 이름 [품번] 형식으로 자동 변경
     3 = 이전 자동 변경 UNDO 복구
     ※ 2번을 선택하고 폴더를 Y로 확인했다면 추가 YES 없이 자동 변경합니다.
  2. 검사할 게임 압축파일 폴더의 전체 경로를 입력하거나,
     경로 없이 Enter를 눌러 Windows 폴더 선택창을 엽니다.
     예: C:\Games\Archive
  3. 선택한 폴더 경로가 다시 표시됩니다.
     "이 폴더가 맞습니까?" → Y 입력 시에만 스캔 시작
     그 외에는 취소 (압축파일 검사·결과 TXT 생성 없음).
     ※ 명령줄에서 폴더 인자를 직접 넘겨도 Y 확인이 필요합니다.
  4. 진행률과 DLsite→Steam 검사 결과가 끝날 때까지 확인합니다.
  5. 기본 저장 위치:
       검사 폴더\PlayDock_Results\검사일시\
  6. 검사 결과 파일은 하나입니다:
       PlayDock_Complete_Scan_And_AI_Prompt.txt
  7. 공식 확인된 작품정보는 설치된 PlayDock의
       <PlayDock 설치 폴더>\data\playdock.db
     한 곳의 works 테이블에 저장합니다.
     스캐너가 설치 위치를 모르면 PlayDock 설치 폴더를 지정할 수 있습니다.
     PlayDock가 설치되지 않았으면 TXT만 생성하고 임의의 DB를 만들지 않습니다.
     과거 %LOCALAPPDATA%\PlayDock\official_works.sqlite3는 이전용으로만 남깁니다.

검사에 실패한 게임이 있다면 TXT 내용:
  - 요약: 전체/공식 확인/일부 확인/제외 수
  - 1부: AI 조사·이름 변경 도구 지침과 제외된 게임만
      A. 식별번호 없음 (공식 사이트 조회를 시작하지 않은 파일)
      B. 식별번호 존재하지만 공식 조회 실패 (기존 품번부터 재검증)
  - 2부: 공식 확인·일부 확인 게임만 간결하게 기록 (참고용)
      1부에 나온 제외 게임을 2부에 반복하지 않아 복사할 내용이 줄어듭니다.
  - AI는 공식 품번과 동일 게임 근거를 조사하고 마크다운 결과표를 작성합니다.
  - 상태는 official_confirmed / candidate / unknown만 허용합니다.
    후보/미확인 항목의 파일명은 변경하지 않습니다.
  - 1부 맨 아래에는 PowerShell 이름 변경 기본 코드가 통째로 포함됩니다.
  - AI는 엔진을 새로 개발하지 않고, 코드 속 JSON 배열의
    OldName / NewName 항목만 공식 확인 결과에 맞춰 채웁니다.
  - PS1 기본 코드의 SHA-256 무결성을 실행할 때 자동 검사합니다.
    AI가 JSON 데이터 이외의 코드를 바꿨다면 변경을 실행하지 않습니다.
  - 원래 PlayDock 검사 EXE에서 다음 명령으로 AI가 완성한 PS1을 독립 검증할 수도 있습니다:
      PlayDock-ID-Scan-And-Prompt.exe --verify-rename-script "rename_games.ps1"
    코드 형식 검증은 작품 동일성을 증명하지 않으므로 이용자가 마지막으로 확인해야 합니다.
  - 게임 폴더를 수동으로 선택한 직후, 경로를 보여주고 Y로 한번 더 확인합니다.
  - 되돌리기는 파일 ID + 크기 + 생성/수정 시각 + SHA-256 내용 서명을 비교합니다.
    작은 압축파일은 전체 바이트, 큰 압축파일은 처음/끝 64KiB만 읽습니다.
    압축을 풀거나 압축 내부 파일 목록을 분석하지 않으며, 큰 파일의 중간부분 변조까지
    완전히 검증하는 전체 해시는 아닙니다.
    파일이 교체/수정됐으면 자동 복구를 건너뛰어 다른 파일 손상을 방지합니다.

  - 이용자는 AI가 제공한 rename_games.ps1 파일을 검토하여 실행하면 됩니다.
    Windows 폴더를 직접 선택해 1=미리보기, 2=YES 후 변경, 3=UNDO 후 복구를 사용합니다.
  - PS1 실행이 어려우면 AI에게 간단한 실행.cmd를 함께 제공해 달라고 요청하세요.
  - 다른 코드 수정은 하지 않도록 지시되어 있어 AI 출력의 오류 가능성을 줄였습니다.

이용자가 해야 할 일:
  TXT를 메모장으로 엽니다.
  Ctrl+A → Ctrl+C → 자신의 ChatGPT/Claude 등 AI 채팅창에서 Ctrl+V.
  TXT 1개만 복사하면 됩니다. JSON이나 다른 TXT를 첨부할 필요가 없습니다.
  AI 조사 대상은 1부에 명시된 '제외' 게임만입니다.
  이후 AI가 제공하는 이름 변경 도구는 미리보기와 최종 승인 후에 실행합니다.
  끝까지 찾지 못한 게임은 수동으로 확인하거나 원래 파일명을 유지합니다.

검사에 실패한 게임이 하나도 없다면:
  똑같이 TXT 하나만 생성되며, 전체 검사 결과와 'AI 조사 불필요' 안내만 들어갑니다.
  AI 조사 프롬프트는 포함되지 않습니다.

실행 명령줄 예시:
  PlayDock-ID-Scan-And-Prompt.exe "C:\Games\Archive"
  PlayDock-ID-Scan-And-Prompt.exe "C:\Games\Archive" --output "D:\ScanResults"
  PlayDock-ID-Scan-And-Prompt.exe "C:\Games\Archive" --top-level

안전/프라이버시
  - 결과는 UTF-8 BOM을 사용해 Windows 메모장에서 한글을 표시합니다.
  - 게임 압축파일을 풀거나 내부 내용을 읽지 않습니다.
  - 전체 폴더 경로는 TXT에 넣지 않습니다. 파일명·품번·공식 URL만 기록합니다.
  - 개인 GitHub 계정, 개발 브랜치, 개발 자료는 TXT 및 공개 EXE에 넣지 않습니다.
  - AI 조회나 이름 변경은 이용자가 자신의 AI와 별도 진행합니다.
  - 조회 실패는 미등록, 비게임, 잘못된 게임이라는 판정이 아닙니다.
  - 하위 폴더까지 압축파일을 찾지만 심볼릭 링크를 따라가지 않습니다.
  - 같은 이름의 파일이 여러 곳에 있으면 자동 이름 변경을 권장하지 않습니다.
  - 프로그램에서 AI API 키·사용자 인증키·개인 게임 목록을 수집하지 않습니다.
  - 검사 중 중단하거나 실패하면 정상 완료된 TXT로 표시하지 않습니다.


자동 이름 변경 기능 (시작 옵션 2)
  - 기존 폴더 Y 확인 이후 품번 검사에 성공한 파일만 처리합니다.
  - 예: RJ01234567.zip → 공식 작품명 [RJ01234567].zip
        [Steam 1091500].7z → 공식 작품명 [Steam 1091500].7z
  - 파일명이 품번만으로 이루어진 경우에만 변경합니다.
    버전·패치·기존 게임명이 있으면 안전을 위해 그대로 둡니다.
  - 품번이 여러 개이거나 공식 조회 실패/일부 확인, 이름 충돌/중복,
    잘못된 Windows 파일명은 변경하지 않습니다.
  - 시작 옵션 1은 파일명을 전혀 변경하지 않습니다.
  - 변경 이력은 사용자 개인 폴더
      %LOCALAPPDATA%\PlayDock\AutoRenameHistory
    에 저장합니다. 검사 결과 폴더에는 계속 TXT 하나만 생성됩니다.
  - 검사는 압축파일명만 이용하며 아카이브를 해제하거나 내부를 읽지 않습니다.
  - 변경 여부를 복구할 때는 Windows 파일 ID, 크기 및 수정 시각으로
    같은 파일인지 검사합니다. 파일 자체가 수정/교체됐으면 복구하지 않습니다.
  - 원상복구: 다음 실행 시 시작 옵션 3 → 폴더 선택 → Y → UNDO.
  - 기존 AI 생성 PS1의 YES 승인·UNDO는 별도의 기능으로 유지됩니다.

명령행 옵션:
  --rename-code-only    시작 옵션 2를 명령행에서 명시적으로 활성화
  --undo-renames        자동 이름 변경 복구 (폴더 Y와 UNDO 승인 필요)
  --self-test-renames   임시 가짜 파일로 이름 변경 및 복구 자체 테스트

  --playdock-folder "C:\Program Files\PlayDock"  PlayDock 설치 폴더 지정 및 기억
