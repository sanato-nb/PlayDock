PlayDock — 폴더 한 번 선택하는 간편 파일명 변경기

사용 방법 (JSON 파일을 직접 선택할 필요가 없습니다)
  1. 제공한 ZIP을 한 폴더에 모두 압축 해제합니다.
  2. PlayDock-One-Folder-Renamer.exe를 실행합니다.
  3. [게임 압축파일 폴더 선택]에서 ZIP/7z/RAR 게임들이 있는 폴더를 선택합니다.
     선택한 폴더의 하위 폴더에 있는 압축파일도 찾아봅니다.
  4. 프로그램이 같은 폴더에 있는 PlayDock_Rename_Data.json을 자동으로 읽고,
     조사된 DLsite/Steam 품번을 공식 사이트에 다시 확인합니다.
  5. 이름 변경 미리보기를 확인한 뒤 [확인된 파일 이름 변경]을 누르고 승인합니다.
  6. 못 찾은 게임이나 DLC/합본/공식 조회 실패 항목은 바꾸지 않고
     [못 찾은 게임 수동 처리 목록 저장]으로 CSV를 만들어 직접 확인합니다.
  7. 잘못 바꿨다면 [최근 변경 취소]를 눌러 최근 변경부터 한 건씩 복구합니다.

중요
  - 실행파일만 따로 옮기지 마세요. PlayDock_Rename_Data.json이 곁에 있어야 합니다.
  - 이 JSON은 사용자만을 위해 준비한 조사 기록이며 공개 GitHub 소스/배포에는 들어가지 않습니다.
  - 공식 조회의 성공은 압축파일 내용이 똑같은 게임이라는 증거가 아닙니다.
    변경 전 작품명과 실제 압축파일명이 같은 게임인지 최종 확인해야 합니다.
  - 2026-11-22 조사 기록에서 DLC·합본 등 동일성 확인이 필요한 작품은 수동 처리합니다.
  - 조사 결과에 품번이 없으면 자동으로 품번을 만들어 붙이지 않습니다.
  - DLsite/Steam 공식 페이지 접근 장애나 판매 중단이 있으면 자동 변경하지 않습니다.
  - 같은 이름이 서로 다른 하위 폴더에 있거나, 변경하려는 이름의 파일이 이미 있으면 건너뜁니다.
  - 실제 게임 압축파일의 내부는 열거나 수정하지 않습니다.
  - API 키나 AI 서비스 연결은 필요 없으며 전체 파일 경로는 인터넷에 전송되지 않습니다.
  - 이름 변경 기록은 로컬 %LOCALAPPDATA%\PlayDock\folder-rename-history.jsonl에 보존됩니다.
  - ZIP 전체 압축 해제 후 EXE를 실행해, 게임이 있는 폴더만 선택하면 됩니다.
