PlayDock — DLsite 양방향 검색 실험판 (2026-11-21)

폴더에 두 개의 서로 독립적인 Windows 실행파일이 있습니다.

1) PlayDock-Name-to-Code.exe
   게임 이름을 입력해 DLsite 품번(RJ/VJ/BJ/EJ)을 검색합니다.
   [압축파일 선택 (여러 개 가능)] 또는 [폴더 내 압축파일 선택]을 누르세요.
   게임명 입력란에 작품 이름을 직접 적어도 됩니다.
   선택한 파일은 실제로 열지 않고 파일명에서 게임 이름을 추출합니다.
   DLsite 일반 검색 HTML에서 공식 작품 링크를 먼저 찾습니다.
   링크가 없으면 Bing/Google/DuckDuckGo/Mojeek 일반 검색 HTML을 보조로 사용합니다.
   공식 작품 페이지의 품번과 이름을 다시 확인합니다.
   검색 후보만 나온 경우는 공식 확인으로 처리하지 않습니다.

2) PlayDock-Code-to-Name.exe
   RJ12345678처럼 품번을 입력해 DLsite 공식 이름을 확인합니다.
   [압축파일 선택 (여러 개 가능)]으로 ZIP/7z/RAR을 고르거나,
   [폴더 내 압축파일 선택]을 사용하면 파일명에 포함된 품번을 자동 추출합니다.
   품번만 직접 입력하는 기존 방식도 계속 지원합니다.
   파일명에 품번이 없거나 여러 개면 자동 선택하지 않고 경고합니다.
   공식 작품 HTML을 직접 확인하며, 조회 실패를 미등록으로 단정하지 않습니다.

공통 기능
- API 키 불필요. JSON API 또는 유료 검색 API 호출 없음.
- 공개 웹페이지의 HTML만 읽음. 사용자 압축파일을 열거나 압축 해제하지 않음.
- 선택한 로컬 파일의 전체 경로를 웹으로 보내지 않고 이름만 검색함.
- 여러 압축파일 동시 선택, 폴더 직하위 압축파일 수집, 선택 목록에서 제거,
  직접 입력과 파일 선택 혼합 가능. 최대 1,000개 일괄 검색.
- 검색 진행률, 중단, 결과 JSON/CSV 저장. 결과에는 선택했던 원래 파일명과
  입력 방식(파일 선택 / 직접 입력)을 함께 남깁니다.
- 후보를 더블클릭하면 공식 상품 웹페이지를 브라우저로 엽니다.
- 사이트가 자동 조회를 차단하면 [브라우저에서 직접 찾기] 버튼으로
  기본 브라우저의 일반 Google 검색 또는 공식 DLsite 작품 페이지를 열 수 있습니다.
- [공식 제목 일치], [공식 품번 확인], [검색 링크 후보]를 엄격히 구분합니다.
- 게임 유형/버전/실제 압축파일 내용은 검증하지 않습니다.
- 개인 입력 내용과 검색 결과는 GitHub에 업로드하지 않습니다.

주의
- DLsite 검색 HTML은 JavaScript 렌더링 또는 접근제한으로 작품 링크가
  보이지 않을 수 있습니다. CAPTCHA나 성인인증 등을 우회하지 않습니다.
- 검색 오류나 후보 없음은 '상품이 없다'는 뜻이 아닙니다.
- 검색 결과에 동명이작, 다른 언어, 번역판이 섞이면 후보를 수동 검토하세요.
- 네트워크 접속이 필요합니다. 검색 사이트 정책·구조 변경에 영향을 받습니다.
- 창이 뜨지 않으면 EXE를 직접 실행하고 Windows SmartScreen 메시지를 확인하세요.
- 실험 버전이며 PlayDock 메인 앱/DB를 수정하지 않습니다.

최종 정확도는 실제 사용자 데이터 검증 전까지 미측정입니다.
