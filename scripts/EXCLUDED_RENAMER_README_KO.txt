PlayDock — 제외 게임 파일명 변경기 (독립 실행판)
실행 파일: PlayDock-Excluded-Renamer.exe
대상: Windows 10/11, ZIP/7z/RAR 압축파일
API 키/유료 서비스: 불필요

목적
  기존 DLsite→Steam 검색 프로그램은 이름을 찾지 못하면 '제외'로 분류합니다.
  그 제외 목록을 ChatGPT 등에 전달해 식별번호를 조사한 후
  이 독립 이름 변경기에서 재검증·승인·파일명 변경하고
  그래도 못 찾은 게임은 사용자가 직접 처리합니다.

사용 순서
  1. DLsite→Steam 검사기를 실행하고 PlayDock_DLsite_Steam_Results.json 저장.
  2. '제외 목록+AI 프롬프트'를 생성해 AI에 전달.
  3. 조사 결과 PlayDock_AI_Research_Results.json 다운로드.
  4. 이 프로그램을 실행하고
       [1. 제외 목록 JSON]에서 검사 결과 JSON 또는 PlayDock_Excluded_Research.json 선택.
       [2. AI 조사 결과 JSON]에서 AI 결과 JSON 선택.
       [3. 두 JSON 대조하여 목록 표시] 클릭.
  5. [4. 실제 압축파일 선택] 또는 [압축파일 폴더 선택]으로 실제 파일 연결.
     파일명(경로 제외)이 JSON의 원본 파일명과 정확히 같아야 합니다.
     서로 다른 폴더에 같은 파일명이 있으면 자동 변경을 거부합니다.
  6. [5. 공식 품번 재확인]으로 AI의 '공식 확인 제안' 항목만 공식 사이트 재조회.
     '후보'와 '미확인'은 자동 적용하지 않습니다.
  7. 해당 게임이 맞는지 직접 확인한 뒤 행을 선택해
     [6. 선택한 파일명 변경 승인]에서 원래 파일명/새 파일명을 비교하고 승인.
     기존 파일의 확장자·버전·번역·DLC 태그는 보존하고 품번만 추가합니다.
     예: BUZAMA 2.7z → BUZAMA 2 [RJ01052720].7z
  8. [7. 못 찾은 게임 · 수동 처리 목록 저장]으로 수동 확인 대상 CSV를 저장.
     수동 확인 시 DLsite와 Steam을 직접 검색한 뒤 정답일 때만 Windows 탐색기에서
     [RJ번호] 또는 [Steam 숫자]를 추가하세요. 없으면 원래 이름을 유지하세요.
  9. 잘못 변경했다면 [원상복구]를 눌러 가장 최근 이름 변경 1건씩 되돌릴 수 있습니다.

분류
  'AI 공식 확인 제안': AI가 같은 게임이라고 제안. 아직 실제 공식 재조회 전.
  '공식 재조회 성공': 공식 품번과 작품명 재확인. 파일 동일성은 사용자 확인.
  '후보 · 수동 확인': AI 결과가 확실하지 않아 자동 변경 금지.
  '미확인 · 수동 검색': DLsite/Steam 품번을 못 찾음. 자동 변경 금지.
  '입력 오류': URL/품번/원본 파일명이 일치하지 않는 AI JSON. 자동 변경 금지.

보안 및 주의
  - AI 조사 결과는 제안일 뿐, 이름 변경 권한이 아닙니다.
  - 실제 로컬 압축파일을 사용자가 명시적으로 선택해야 합니다.
  - 인터넷 조회는 공식 식별번호에 대해서만 수행합니다.
  - 원본 압축파일 내용은 열거나 압축 해제하지 않습니다.
  - 다른 파일이 같은 이름을 쓰고 있으면 덮어쓰지 않습니다.
  - 로컬 전체 경로는 사용자의 PC 내에만 보관합니다.
  - 변경 기록: %LOCALAPPDATA%\PlayDock\rename-history.jsonl
  - AI 검증이 실패하면 URL에 접근할 수 없거나 판매가 중지되었을 수도 있습니다.
    '제외'는 가짜 게임이라는 뜻이 아닙니다.
  - 본 프로그램은 PlayDock 본체의 설치/게임 목록 DB를 수정하지 않습니다.
  - 기본 파일명은 건드리지 않으므로, 확인되지 않은 게임을 억지로 바꾸지 않습니다.
