# PlayDock 게임 정체 판독기 — v0.8 회귀 검증 체크리스트

> **v0.8 정확도 보강:** itch.io 개별 상품 홈만 인정(댓글·개발일지 제외), 웹 결과의 다른 게임 RJ 번호를 공식 후보로 잘못 승격하지 않음, 동일 파일에서 DLsite/Steam 두 후보의 공식 상품번호가 섞이지 않음, 내부 EXE·폴더명과 외부 제목의 정확한 일치를 별도 근거로 표시하지만 '일치 확인'에는 사용하지 않음. [v0.8 개발 기록](V08_ACCURACY_2026-11-19_KO.md) 참고.

> **v0.7 추가 완료 기준:** 기본 GUI/CLI는 엔진 설정·JSON·INI 등의 본문을 열지 않고 내부 **파일명·경로·확장자·크기·엔진 구조**를 활용합니다. README는 최대 2개 파일에서 제목·작품번호·Steam ID 같은 명시 필드만 추출합니다. 공식 품번 및 다른 내부 코드가 많아도 압축파일명 제목 검색을 보장합니다. 합성 ZIP·모의 검색 및 `--self-test` 회귀 검사 추가. [v0.7 구현 기록](V07_IMPLEMENTATION_2026-11-19_KO.md) 참고.

> **v0.6 구현 결과:** 합성 압축파일/모의 응답 기반 P0 검색 복구, 쿨다운/검색 실패 구분, 캐시 재사용, 공식 플랫폼 연결, 시간 계측 테스트를 추가했습니다. 최신 구현 개요는 [v0.6 실제 구현 기록](V06_IMPLEMENTATION_2026-11-19_KO.md) 참조. 아래의 129개 수치는 v0.5 개인 배치 기준이며 v0.6 실측 성능이 아닙니다.

> 이 체크리스트는 **v0.5의 실사용 누락·성능 문제를 안전하게 재현하기 위한 합성 테스트 기준**이다. 실제 개인 압축파일명/내부 상대 경로는 테스트 소스에 복사하지 않는다.
>
> 기준 데이터: v0.4 검사 128개, v0.5 검사 129개(공통 128개). 상세 파일별 JSON과 비교 보고서는 사용자 개인 자료이므로 저장소에 미포함.

## 최소 완료 조건

| 구분 | 합성 시나리오 | 합격 기준 |
|---|---|---|
| 검색 근거 | 가짜 한국어 `별하늘 여행.zip` + 내부 `별하늘 여행.exe` | **이름/내부 단서 전부 모은 후** 첫 네트워크 호출 |
| 외부 작품번호 단서 | 쿼리 실패, 웹 결과 제목에 가짜 `RJ09999999` | 카탈로그 제3자 **미확인 후보**로 남김; 공식 조회 실패 시 공식 확정 금지 |
| 시리즈 구분 | 가상 `작품 2` / `작품 3`의 각각 다른 ID | 후속작을 같은 상품으로 병합하지 않음 |
| 검색 오류 | 일반 웹 `RuntimeError` 두 번, 그 뒤 추가 파일 | `lookup_error`와 `skipped_due_to_cooldown`을 실제 `not_found`와 구별 |
| 재시도 | 쿨다운 이후 서비스 복구 시나리오 | 중단된 개별 항목을 제한된 횟수로 재검색 가능; 원본 파일 재스캔 최소화 |
| 캐시 | 같은 품번이 여러 파일의 이름/내부에 반복 | 동일 검색을 한 번 수행하되 오류 응답은 정상 캐시하지 않음 |
| 별칭 | 영어·일본어를 공식 페이지에서 **명시적으로 병기**한 한 상품 | 같은 공식 카탈로그 후보로 병합, 내부 정체 확정은 별개 |
| 서로 다른 공식 ID | 같은 게임명이나 다른 공식 등록번호 | **자동 병합 금지**; 확인 필요/충돌 사유 보존 |
| 패치/본편 | 원작 + 별도 번역 패치 코드가 포함된 게임 폴더 | 출처 관계 구분, 패치 상품 ID를 곧바로 본편 ID로 확정하지 않음 |
| DLC/합본 | DLC 1개, 본편 2개가 묶인 합성 이름 | 상품 유형과 패키지 유형 따로 기록; 자동 단일 본편 확정 금지 |
| 암호화 ZIP | 암호화 플래그가 설정된 합성 파일 | **압축 내부 목록/설정 파서 호출 안 함**, 파일명만 검색 |
| 솔리드 7z | 설정 읽기가 높은 비용/불가한 모의 목록 | `index_only` 한계 명시, '불일치'로 잘못 단정하지 않음 |
| 파일 불변 | 합성 압축파일의 사전/사후 SHA-256 비교 | 동일 해시, 원본 파일명 유지, 내부 파일 실행 없음 |
| 정보 보호 | 가상 개인 절대 경로 포함 압축파일 | 웹 검색어에 절대 경로·내부 설정 원문 유출 없음 |
| UI | 128개 파일을 모의로 순차 검사 | 상단 진행바 0~100%, 현재 파일/단계 표시, 중지 시 결과 보존 |
| 단계별 시간 | 모의 단계별 측정 | `name/encryption/index/metadata/search/verify`와 총 시간이 비음수로 기록되고 전체에 오류 처리 시간 포함 |
| EXE | Windows 빌드 `--self-test` | 수동 빌드 아티팩트 정상, 개인 DB/API 키/압축 포함되지 않음 |

## 정량 지표

- **정확도:** 수동으로 공식 작품번호·제목·본편/패치/DLC 관계를 확인한 독립 정답표에 대해서만 계산. `candidate_found`나 `catalog_status=official_game_found`를 그대로 정답 취급하지 않음.
- **후보 발견률:** 검증된 후보, 미확인 제3자 후보, 단순 웹 단서의 각 분모/분자 별도 기록.
- **검색 복구:** 검색 오류 파일, 쿨다운 생략 파일, 나중에 성공한 재검색 파일 수 분리.
- **성능:** 동일 파일/동일 네트워크 환경에서 `analysis_seconds` 파일별 합, 초당 처리량, 각 단계별 평균·중앙값·상위 백분위 기록. 검색을 생략한 효과를 따로 분리.
- **보안:** 파일 원본 불변, 자동 연결 `false`, 패치/합본 오분류 없음.

## 최근 실제 검증 기준(업로드 JSON 집계)

- v0.4 **128개**, 전체 파일별 처리시간 합 **1068.725초**.
- v0.5 **129개**, 전체 **318.092초**, v0.4와 공통 128개 **314.084초**.
- v0.5 카탈로그: 공식 작품 발견 상태 79개, 웹 후보 2개, 복수 후보 1개, 조회 오류 30개, 미발견 17개.
- v0.5 검색: 실제 요청 162, 캐시 적중 5, 검색 생략 20, 오류 39.
- **주의:** v0.5 속도 개선에는 오류 후 검색 생략이 포함되어 실제 정답률 향상 또는 동일 조건에서의 속도를 보증하지 않음.

## 자동 테스트 명령어

```bash
python -m pip install -r requirements.txt pytest
python -m pytest -q
python -m pytest -q tests/test_v05_search_and_catalog_experiment.py
python -m pytest -q tests/test_identity_verification_stage6_experiment.py tests/test_internal_first_search_v03_experiment.py
```
