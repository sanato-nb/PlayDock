# DLsite 작품 등록·게임 여부 판별기 (독립 실험)

> **아직 PlayDock 본체에 연결하지 않은 기능 실험입니다.** 코드를 실행해도 사용자 게임/압축파일/설치폴더/이미지/SQLite/설정을 읽거나 변경하지 않습니다.

## 첫 번째 목표

게임 이름 또는 `RJ / VJ / BJ / EJ` 품번을 받아 **DLsite에 실제로 같은 품번의 작품이 등록되었는지**, 그 작품이 **게임 형식인지** 구분합니다.

**중요:** DLsite 품번은 음성·CG·만화 등 게임 이외의 작품에도 부여됩니다. 따라서 품번 존재만으로 게임이라고 판단하지 않습니다. 원본 DLsite JSON의 `work_type`을 확인합니다.

## 판정 상태

| 결과 | 의미 |
|---|---|
| `confirmed_game` | DLsite 원본 작품 코드가 일치하고 게임 종류가 확인되며, 제목이 있으면 공식 제목도 일치함 |
| `registered_non_game` | DLsite 등록 작품은 맞지만 명시적인 비게임 형식 (예: `SOU`, `ICG`) |
| `registered_type_unknown` | DLsite 등록은 확인됐지만 작품 형식이 없거나 미지원 값임 |
| `needs_review` | 공식 제목이 로컬 이름과 다르거나 후보가 여러 개여서 사람의 확인이 필요함 |
| `unverified` | 등록 증거를 확인하지 못함. **DLsite에 없다고 단정하지 않음** |
| `lookup_unavailable` | 접속 실패, 차단, 응답 오류 등으로 검증 불가 |
| `input_error` | 검색값/작품 코드 오류 |

## 검사 순서

1. 제목/파일명에서 작품 코드를 추출하고, 사용자가 직접 입력한 품번이 있으면 우선합니다.
2. 작품 코드가 있으면 해당 품번의 **DLsite 원본 JSON**을 조회합니다. 응답 속 `workno`/상위 품번 키와 **정확히 일치**하는 경우만 인정합니다.
3. `work_type`을 확인해 게임/비게임/종류 미확인으로 분류합니다. 게임 이름이 다르면 등록 작품이어도 본 게임과 동일한지는 **확인 필요** 처리합니다.
4. 코드가 없으면 사용자가 명시적으로 이름 검색을 허용했을 때만 공개 검색에서 **DLsite 작품 페이지 링크**를 추출하고, 후보 코드를 다시 사이트 JSON으로 검증합니다.
5. 검색 결과가 없거나 사이트 접근이 불가능하면 '미확인/조회 불가'로 남깁니다. 다른 플랫폼 게임이라고 자동 판정하지 않습니다.

게임 판정의 근거는 구조화된 `work_type`이며 파일 확장자, 다운로드 형식이나 RJ 품번의 접두어만으로 판단하지 않습니다. `ETC` 등 불명확한 분류는 '미확인'입니다. 제목 비교는 완전 일치 위주로 보수적으로 수행하여 시리즈 번호를 구별합니다.

## 독립 실행

저장소 최상위 경로에서 실행하세요.

```powershell
# 네트워크 없이 코드만 보여줌 (기본 동작)
python -m experiments.dlsite_detector.cli "샘플 게임 [RJ01081508].zip"

# 해당 품번의 현재 DLsite 등록 상태 확인 (인터넷 사용을 명시적으로 허용)
python -m experiments.dlsite_detector.cli "RJ01081508" --online

# 품번이 없는 작품명으로 후보 검색·검증 (ddgs 설치 필요)
python -m experiments.dlsite_detector.cli "게임 제목" --online --search-title

# 다른 도구에서 처리할 수 있도록 구조화 결과 출력
python -m experiments.dlsite_detector.cli "RJ01081508" --online --json
```

`pip install -r requirements.txt`로 기존 PlayDock의 패키지를 설치할 수 있지만, **독립 판별 엔진 자체는 Python 표준 라이브러리만 사용**합니다. 제목 검색은 선택적으로 `ddgs`를 사용합니다.

## 개발자가 확인할 테스트

```bash
python -m pytest -q tests/test_dlsite_detector_experiment.py
```

CI에서는 실제 DLsite 사이트를 호출하지 않고 모의 JSON/HTTP 응답으로 검증합니다. 아직 **실제 DLsite 사이트의 최신 동작과 검색 정확도**, Windows 환경 연동을 검증한 상태는 아닙니다.

## 본체 이식 전 완료 조건

- 실제 게임·비게임·제목 오타·다국어 제목·품번 없는 게임을 이용해 오탐/누락 확인
- DLsite 내부 JSON 구조 변경·접속 차단·403/429 오류에 대한 테스트
- 제품과 로컬 게임의 연결에 대한 사용자 확인 절차 확립
- 독립 검사 결과가 안정적인 경우에만 Controller/Service로 포팅
- 통합 후에도 **게임 원본 파일·작품 코드·제목·설정·모음집 자동 변경 금지**

### 접근 범위

이 기능은 DLsite 계정 로그인·구매 내역·성인 인증 우회 기능을 갖지 않습니다. 사용자가 지시한 코드/제목에 대해 소수의 공개 요청만 수행합니다. DLsite 작품 JSON 경로는 비공식 엔드포인트라 이용 가능성이 보장되지 않으며, 제목 검색이 단순 검색 결과로 작품 일치를 확정하는 일은 없습니다.
